# 제출 전 자기점검

## ① 데이터 불러오기

- [ ] `import seaborn as sns` 를 썼다
- [ ] `df = sns.load_dataset("...")` 로만 불러왔다 (CSV 업로드만 하지 않음)
- [ ] 이름이 **`tips` / `iris` / `mpg` / `titanic` / `flights` / `exercise` 중 하나**이다
- [ ] **`penguins` 가 아니다**
- [ ] `mpg` 또는 `titanic` 이면 `dropna()` 를 했다(권장)

---

## ② 구조적 시각화 (40점 · 03-03)

- [ ] 그래프 **2종 이상** (분포 / 비교 / 관계 등)
- [ ] 제목·가로축·세로축이 있다
- [ ] 실행 시 **오류 없이** 그래프가 나온다
- [ ] 분석 목적과 그래프 종류가 맞다

---

## ③ 그래픽 강조 (30점 · 03-04)

- [ ] `color=`, `hue=`, `s=` 등이 **한 곳 이상** 있다
- [ ] 강조한 내용을 **한 문장**으로 적었다
- [ ] PNG가 있으면 강조가 보인다

---

## ④ 해석·스토리 (30점 · 03-05)

- [ ] 서술에 **본인 그래프·수치** 근거가 있다
- [ ] 결론·주의점이 있다
- [ ] AI·친구 문장을 그대로 쓰지 않았다

---

## ⑤ 제출물

- [ ] 노트북에 **DATASET / load_dataset** 이 보인다
- [ ] 서술 ①~⑤ 블록을 채웠다
- [ ] 파일명 규칙(수업 안내)을 맞췄다
