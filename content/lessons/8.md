## 실습 전 공통 준비 코드

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** **`import`와 `df`를 만드는 줄**은 **한 블록**입니다. **숫자(`shape`)**와 **표(`head`)**는 각각 **다음 셀**에 두었습니다. **그래프**는 `plt` 줄을 **한 블록**에 이어 붙이세요. **산점도와 상관 숫자**는 결과가 달라서 **블록을 나누었습니다.**

**준비** — 라이브러리 + 데이터 + 결측 제거

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("penguins")
df = df.dropna()
```

**출력** — 크기

```python
df.shape
```

**출력** — 앞부분

```python
df.head()
```

## 3. 시각화 예시: 종별 평균 체중

**읽는 법:** 막대 높이가 클수록 그 종의 **평균 체중(g)**이 크다. 어떤 종이 가장 무거운지 한 문장으로 정리해 본다.

```python
df.groupby("species")["body_mass_g"].mean().plot(kind="bar", color="steelblue")
plt.title("Mean body mass by penguin species")
plt.xlabel("species")
plt.ylabel("mean body_mass_g")
plt.show()
```

---

## 4. 인사이트 질문 예시

- 어떤 종이 평균 체중이 가장 큰가?
- `bill_length_mm`과 `bill_depth_mm`의 상관은?
- 섬(`island`)마다 종 구성이 다른가?

**그래프** — 산점도 (한 셀)

```python
plt.scatter(df["bill_length_mm"], df["bill_depth_mm"], alpha=0.6)
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.title("Bill length vs bill depth")
plt.show()
```

**숫자 출력** — 상관계수 (다음 셀)

```python
df["bill_length_mm"].corr(df["bill_depth_mm"])
```
