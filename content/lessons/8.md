## 1. EDA(탐색적 데이터 분석)란? 🔍

### EDA = Exploratory Data Analysis

**탐색적 데이터 분석**은 마치 **탐정이 사건을 수사**하는 것과 비슷해요!

| 단계 | 탐정의 수사 | 데이터 분석 |
|------|------------|-------------|
| 1 | 사건 현장 둘러보기 | 데이터 살펴보기 |
| 2 | 단서 정리하기 | 데이터 정제하기 |
| 3 | 증거 분석하기 | 통계 계산하기 |
| 4 | 사건 재구성하기 | 시각화하기 |
| 5 | 범인 찾기! | 인사이트 도출! |

> 💡 **EDA의 핵심 정신**
> "데이터에 어떤 이야기가 숨어있을까?" 하고 **호기심을 가지고** 들여다보는 거예요!

### 왜 EDA가 중요할까?

- 🚀 **본격적인 분석 전 데이터 이해**
- 🐛 **숨겨진 오류나 이상치 발견**
- 💡 **분석 방향 결정**
- 📊 **시각화로 패턴 찾기**

## 3. 1단계: 데이터 확인 🔎

분석할 데이터를 **처음 만났을 때** 무엇을 봐야 할까요?

### 체크리스트

- ✅ 행과 열이 몇 개인가?
- ✅ 어떤 종류의 데이터가 있는가?
- ✅ 데이터 타입은 적절한가?
- ✅ 결측치가 얼마나 있는가?

### 실습: 데이터 확인 코드

```python
import pandas as pd
import matplotlib.pyplot as plt

# 데이터 불러오기
df = pd.read_csv('students.csv')

# 1️⃣ 처음 5개 행 살펴보기
print("📌 데이터 미리보기")
print(df.head())

# 2️⃣ 데이터 크기 확인
print(f"\n📌 데이터 크기: {df.shape[0]}행 × {df.shape[1]}열")

# 3️⃣ 데이터 타입 확인
print("\n📌 데이터 정보")
df.info()

# 4️⃣ 열 이름 확인
print(f"\n📌 열 이름: {list(df.columns)}")
```

## 4. 2단계: 데이터 전처리 🧹

### 결측치 확인 및 처리

```python
# 결측치 개수 확인
print("📌 열별 결측치")
print(df.isna().sum())

# 결측치 비율
print("\n📌 결측치 비율 (%)")
print((df.isna().sum() / len(df)) * 100)

# 결측치 처리 (열별로 다르게!)
df['키'] = df['키'].fillna(df['키'].mean())          # 평균
df['몸무게'] = df['몸무게'].fillna(df['몸무게'].median())  # 중앙값
df['수학'] = df['수학'].fillna(df['수학'].mean())

# 처리 결과 확인
print("\n📌 처리 후 결측치")
print(df.isna().sum())
```

### 중복 데이터 확인 및 제거

```python
# 중복 행이 있는지 확인
print(f"중복 행: {df.duplicated().sum()}개")

# 중복 제거
df = df.drop_duplicates()
```

### 이상치 확인 (간단 버전)

```python
# 박스 플롯으로 이상치 확인
df['키'].plot(kind='box')
plt.title('키 분포 (이상치 확인)')
plt.show()
```

> 💡 **이상치(Outlier)란?**
> 다른 데이터와 동떨어진 **이상한 값**이에요. 예를 들어 학생 키 데이터에 230cm가 있다면? 입력 실수일 가능성이 높죠!

### 전체 통계 한눈에

```python
print("\n📌 범주 데이터 통계")
print(df.describe(include='object'))
```

### 그룹별 분석

```python
# 반별 평균
print("\n📌 반별 평균")
print(df.groupby('반').mean(numeric_only=True))

# 성별 평균
print("\n📌 성별 평균 (있다면)")
print(df.groupby('성별').mean(numeric_only=True))
```

### 상관관계 분석

```python
# 어떤 데이터끼리 관련이 있을까?
print("\n📌 상관계수")
print(df.corr(numeric_only=True))
```

> 💡 **상관계수란?**
> 두 데이터의 **관계 강도**를 -1 ~ +1 사이의 숫자로 표현한 거예요.
> - **+1에 가까울수록**: 같이 증가 (키↑, 몸무게↑)
> - **-1에 가까울수록**: 반대로 변함 (스마트폰 사용↑, 시력↓)
> - **0에 가까울수록**: 관계 없음

## 6. 4단계: 시각화 🎨

### 다양한 그래프로 데이터 탐색

```python
import matplotlib as mpl
mpl.rc('font', family='NanumGothic')
mpl.rc('axes', unicode_minus=False)

# 큰 캔버스 만들기 (2x2 = 4개의 그래프)
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# ① 키 분포 히스토그램
axes[0, 0].hist(df['키'], bins=10, color='skyblue', edgecolor='black')
axes[0, 0].set_title('학생 키 분포')
axes[0, 0].set_xlabel('키 (cm)')
axes[0, 0].set_ylabel('학생 수')

# ② 반별 수학 평균 (막대)
반별평균 = df.groupby('반')['수학'].mean()
axes[0, 1].bar(반별평균.index.astype(str), 반별평균.values, color='coral')
axes[0, 1].set_title('반별 수학 평균')
axes[0, 1].set_xlabel('반')
axes[0, 1].set_ylabel('평균 점수')

# ③ 키 vs 몸무게 (산점도)
axes[1, 0].scatter(df['키'], df['몸무게'], color='purple', alpha=0.6)
axes[1, 0].set_title('키와 몸무게의 관계')
axes[1, 0].set_xlabel('키 (cm)')
axes[1, 0].set_ylabel('몸무게 (kg)')

# ④ 과목별 평균 (막대)
과목평균 = df[['국어', '영어', '수학']].mean()
axes[1, 1].bar(과목평균.index, 과목평균.values, color=['gold','green','red'])
axes[1, 1].set_title('과목별 평균 점수')
axes[1, 1].set_xlabel('과목')
axes[1, 1].set_ylabel('평균 점수')

plt.tight_layout()
plt.show()
```

## 7. 5단계: 결론 도출 (인사이트) 💡

### 분석 보고서 작성하기

```python
print("=" * 50)
print("       📊 우리 반 분석 보고서")
print("=" * 50)

# 1. 기본 정보
print(f"\n🎒 분석 대상: {len(df)}명의 학생")
print(f"📐 평균 키: {df['키'].mean():.1f}cm")
print(f"⚖️ 평균 몸무게: {df['몸무게'].mean():.1f}kg")

# 2. 학업 성적
print(f"\n📚 과목별 평균")
for 과목 in ['국어', '영어', '수학']:
    평균 = df[과목].mean()
    print(f"  - {과목}: {평균:.1f}점")

# 3. 상위권/하위권
수학상위 = df.sort_values('수학', ascending=False).head(3)
print(f"\n🏆 수학 TOP 3")
for idx, row in 수학상위.iterrows():
    print(f"  - {row['이름']}: {row['수학']}점")

# 4. 인사이트
print("\n💡 인사이트")
print(f"  - 가장 점수가 높은 과목: {df[['국어','영어','수학']].mean().idxmax()}")
print(f"  - 가장 점수가 낮은 과목: {df[['국어','영어','수학']].mean().idxmin()}")
print(f"  - 1반과 2반 수학 평균 차이: {abs(df.groupby('반')['수학'].mean()[1] - df.groupby('반')['수학'].mean()[2]):.1f}점")

print("\n" + "=" * 50)
```

## 8. 종합 프로젝트: 미니 분석 사례 🎯

### 프로젝트 주제: "우리 반 학생 데이터 분석"

#### Step 1: 분석 질문 정하기

> 🤔 **분석을 시작하기 전에 질문을 정해요!**

좋은 질문 예시:
- ❓ 키와 몸무게는 정말 비례할까?
- ❓ 어느 반이 학업 성적이 가장 좋을까?
- ❓ 운동을 잘하는 학생이 공부도 잘할까?
- ❓ 평균보다 키가 큰 학생들의 특징은?

#### Step 2: 데이터로 답 찾기

```python
# 질문 1: 키와 몸무게의 상관관계
상관 = df['키'].corr(df['몸무게'])
print(f"키-몸무게 상관계수: {상관:.2f}")

if 상관 > 0.7:
    print("→ 강한 양의 상관! 키가 클수록 몸무게도 늘어요!")
elif 상관 > 0.3:
    print("→ 어느 정도 양의 상관이 있어요.")
else:
    print("→ 별 관계가 없네요.")

# 시각화로 확인
plt.scatter(df['키'], df['몸무게'])
plt.title(f'키와 몸무게 (상관계수: {상관:.2f})')
plt.xlabel('키')
plt.ylabel('몸무게')
plt.show()
```

```python
# 질문 2: 어느 반이 가장 잘할까?
반별_평균점수 = df.groupby('반')[['국어', '영어', '수학']].mean()
print(반별_평균점수)

# 시각화
반별_평균점수.plot(kind='bar', figsize=(8, 5))
plt.title('반별 과목 평균 점수')
plt.ylabel('평균 점수')
plt.xticks(rotation=0)
plt.legend(loc='lower right')
plt.show()
```

#### Step 3: 결론 정리

> 📝 **분석 결과 예시**
> 
> **분석 결과:**
> 1. 우리 반 학생들의 평균 키는 **165.2cm**, 평균 몸무게는 **53.4kg**입니다.
> 2. 키와 몸무게의 상관계수는 **0.85**로, 강한 양의 상관관계가 있습니다.
> 3. **2반**이 평균 수학 점수가 가장 높으며 (88점), **3반**이 가장 낮습니다 (75점).
> 4. 영어 과목은 반 간 점수 차이가 가장 적어 비교적 균등합니다.

## 9. 코드 템플릿: 누구나 쓸 수 있는 분석 코드 📝

```python
# ============================================
# 데이터 분석 표준 템플릿
# ============================================
import pandas as pd
import matplotlib.pyplot as plt
import matplotlib as mpl

# 한글 폰트 설정
mpl.rc('font', family='NanumGothic')
mpl.rc('axes', unicode_minus=False)

# 1️⃣ 데이터 불러오기
df = pd.read_csv('파일이름.csv')

# 2️⃣ 데이터 확인
print("📌 1단계: 데이터 확인")
print(df.head())
print(f"크기: {df.shape}")
df.info()

# 3️⃣ 데이터 전처리
print("\n📌 2단계: 결측치 처리")
print("처리 전:", df.isna().sum().sum())
# 숫자형 열은 평균으로 채우기
숫자열 = df.select_dtypes(include='number').columns
for col in 숫자열:
    df[col] = df[col].fillna(df[col].mean())
print("처리 후:", df.isna().sum().sum())

# 4️⃣ 통계량 확인
print("\n📌 3단계: 기술 통계")
print(df.describe())

# 5️⃣ 시각화
print("\n📌 4단계: 시각화")
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 막대 그래프
df.iloc[:, 1].plot(kind='hist', ax=axes[0], color='skyblue')
axes[0].set_title('첫 번째 숫자 열 분포')

# 박스 플롯
df.select_dtypes(include='number').plot(kind='box', ax=axes[1])
axes[1].set_title('전체 분포')
axes[1].tick_params(axis='x', rotation=45)

plt.tight_layout()
plt.show()

# 6️⃣ 결론
print("\n📌 5단계: 인사이트")
print(f"- 데이터 개수: {len(df)}개")
print(f"- 분석한 변수: {list(df.columns)}")
```
