## 3. 시각화 예시: 종별 평균 체중

**읽는 법:** 막대 높이가 클수록 그 종의 **평균 체중(g)**이 크다. 어떤 종이 가장 무거운지 한 문장으로 정리해 본다.

```python
df.groupby("species")["body_mass_g"].mean().plot(kind="bar", color="steelblue")
plt.title("Mean body mass by penguin species")
plt.xlabel("species")
plt.ylabel("mean body_mass_g")
plt.show()
```

> 💡 **인사이트:** Gentoo가 평균 약 5,092g으로 다른 두 종보다 1,300g 넘게 무겁다. Adelie(3,706g)와 Chinstrap(3,733g)은 거의 같아 막대 높이가 나란하다.

## 4. 인사이트 질문 예시

- 어떤 종이 평균 체중이 가장 큰가?
- `bill_length_mm`과 `bill_depth_mm`의 상관은?
- 섬(`island`)마다 종 구성이 다른가?

**그래프** — 산점도 (한 셀)

```python
plt.scatter(df["bill_length_mm"], df["bill_depth_mm"], alpha=0.6)
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.title("Bill length vs bill depth")
plt.show()
```

> 💡 **인사이트:** 전체로 보면 부리가 길수록 깊이는 오히려 얕아지는 약한 음의 관계가 보인다. 점들이 두세 덩어리로 나뉘어 있어, 숨은 그룹(종)이 있을 가능성이 엿보인다.

**숫자 출력** — 상관계수 (다음 셀)

```python
df["bill_length_mm"].corr(df["bill_depth_mm"])   # 두 열의 상관계수(-1~1)를 구한다
```

> 🤔 **반전!** 전체로 보면 상관이 **음수(-0.23)**인데, **종별로 색을 나눠** 보면 종마다 **양의 관계**가 보입니다. (이런 현상을 *심슨의 역설*이라고 해요.)

**그래프** — 종별 색 산점도

```python
import seaborn as sns                                    # seaborn 불러오기
# 종(species)마다 다른 색(hue)으로 점을 찍는다
sns.scatterplot(data=df, x="bill_length_mm", y="bill_depth_mm", hue="species")
plt.title("Bill length vs depth (by species)")           # 제목
plt.show()                                               # 그래프 보이기
```

> 💡 **인사이트:** 종으로 색을 나누니 각 종 안에서는 부리가 길수록 깊이도 커지는 양의 관계가 드러난다. 전체의 음의 상관은 서로 다른 종을 섞어 본 착시였다(심슨의 역설).

## 5. 다양한 그래프 모음 (그룹 · 평균 · 비교)

> 같은 데이터라도 **목적에 맞는 그래프**를 골라야 합니다. 아래 5가지를 직접 바꿔가며 그려 보세요. (각 코드는 **한 셀씩** 실행)

**(1) 그룹별 평균 비교** — 막대그래프

```python
# 종별로 묶어 부리 길이·깊이의 평균을 구한 뒤, 막대로 나란히 비교
df.groupby("species")[["bill_length_mm", "bill_depth_mm"]].mean().plot(kind="bar")
plt.title("Mean bill size by species")   # 제목
plt.ylabel("mm")                         # y축 이름(단위 mm)
plt.show()                               # 그래프 보이기
```

> 💡 **인사이트:** Gentoo는 부리가 길지만(47.6mm) 깊이는 가장 얕아(15.0mm) 길고 가는 형태다. Adelie는 부리가 가장 짧고(38.8mm) 깊은 편이라, 종마다 부리 모양이 뚜렷이 다르다.

**(2) 그룹 안에서 다시 비교** — 성별 평균 체중

```python
# x=종, y=체중, 성별(sex)을 색으로 나눠 그룹 안의 차이까지 비교
sns.barplot(data=df, x="species", y="body_mass_g", hue="sex")
plt.title("Mean body mass by species & sex")   # 제목
plt.show()                                      # 그래프 보이기
```

> 💡 **인사이트:** 세 종 모두 수컷이 암컷보다 무겁다(차이 약 400~800g). 종 평균만 보면 이런 성별 차이를 놓치기 쉽다.

**(3) 개수 비교** — 종 × 성별 마릿수

```python
# 종마다 암수(sex)가 몇 마리인지 막대 개수로 비교
sns.countplot(data=df, x="species", hue="sex")
plt.title("Count by species & sex")   # 제목
plt.show()                            # 그래프 보이기
```

> 💡 **인사이트:** 모든 종에서 암수 마릿수가 거의 비슷해 표본이 한쪽으로 치우치지 않았다. 그래서 앞의 성별 평균 비교를 믿고 해석해도 된다.

**(4) 분포 비교** — 박스플롯

```python
# 종별 체중의 '퍼진 정도'(중앙값·사분위·이상치)를 상자로 비교
sns.boxplot(data=df, x="species", y="body_mass_g")
plt.title("Body mass distribution by species")   # 제목
plt.show()                                        # 그래프 보이기
```

> 💡 **인사이트:** Gentoo는 상자 전체가 위쪽에 있어 중앙값(약 5,050g)도 다른 종보다 1,300g 이상 높다. Adelie와 Chinstrap은 상자가 겹쳐, 평균뿐 아니라 분포 범위도 서로 비슷하다.

**(5) 구성 비교** — 섬별 종 구성 (누적 막대)

```python
# 섬(island) × 종(species) 교차표를 만든다 (각 칸 = 마릿수)
table = pd.crosstab(df["island"], df["species"])
# 교차표를 누적 막대로 그려 섬마다 종 구성이 어떻게 다른지 비교
table.plot(kind="bar", stacked=True)
plt.title("Species composition by island")   # 제목
plt.ylabel("count")                           # y축 이름(마릿수)
plt.show()                                    # 그래프 보이기
```

> 💡 **인사이트:** Gentoo는 Biscoe섬에만, Chinstrap은 Dream섬에만 산다. Adelie만 세 섬 모두에 분포해, 섬마다 종 구성이 뚜렷이 다르다.

**(6) 한 변수 분포** — 히스토그램

```python
# body_mass_g(체중) 한 열이 어떤 값에 몰려 있는지 구간(bins)으로 나눠 센다
sns.histplot(data=df, x="body_mass_g", bins=20)
plt.title("Body mass distribution")   # 제목
plt.show()                            # 그래프 보이기
```

> 💡 **인사이트:** 체중은 3,500~4,000g 구간에 가장 많이 몰려 있고, 5,000g 부근에 또 하나의 작은 봉우리가 있다(무거운 Gentoo 무리). 봉우리가 둘로 보이는 건 서로 다른 종이 섞여 있다는 신호다.

**(7) 관계 한눈에** — 상관 히트맵

```python
# 수치 열들끼리의 상관계수를 한 번에 구한다 (numeric_only=True: 숫자 열만)
corr = df.corr(numeric_only=True)
# 상관표를 색으로 칠하고 숫자(annot)를 함께 표시
sns.heatmap(corr, annot=True, cmap="coolwarm")
plt.title("Correlation heatmap")   # 제목
plt.show()                         # 그래프 보이기
```

> 💡 **인사이트:** 날개 길이와 체중의 상관이 0.87로 가장 강해, 날개가 길수록 무겁다. 부리 깊이는 체중·날개와 음(−)의 관계라, 어떤 쌍이 함께 커지고 어떤 쌍이 반대로 가는지 색만 봐도 한눈에 들어온다.

**(8) 구성 비율** — 파이차트

```python
# 종별 마릿수를 세서 전체에서 차지하는 비율을 원으로 표시 (autopct: % 표기)
df["species"].value_counts().plot(kind="pie", autopct="%1.1f%%")
plt.title("Species ratio")   # 제목
plt.ylabel("")               # 불필요한 y축 라벨 숨기기
plt.show()                   # 그래프 보이기
```

> 💡 **인사이트:** Adelie가 전체의 약 44%로 가장 많고, Chinstrap은 약 20%로 가장 적다. 세 종이 고르게 1/3씩은 아니므로, 종별로 비교할 때 표본 수 차이를 염두에 둬야 한다.

> 💡 **언제 무엇을?** 한 변수 분포 → **히스토그램**, 평균 비교 → **막대**, 그룹 안 차이 → **색(hue) 막대**, 개수 → **countplot**, 분포·이상치 → **박스플롯**, 구성 비율 → **파이/누적 막대**, 관계 한눈에 → **히트맵**.
