## 실습 전 공통 준비 코드

import matplotlib.pyplot as plt

df = sns.load_dataset("penguins")
df = df.dropna()
print(df.shape)
df.head()

## 3. 시각화 예시: 종별 평균 체중

```python
df.groupby("species")["body_mass_g"].mean().plot(kind="bar")
plt.title("펭귄 종별 평균 체중 (g)")
plt.ylabel("g")
plt.show()
```

## 4. 인사이트 질문 예시

- 어떤 종이 평균 체중이 가장 큰가?
- `bill_length_mm`과 `bill_depth_mm`의 상관은?
- 섬(`island`)마다 종 구성이 다른가?

```python
print(df["bill_length_mm"].corr(df["bill_depth_mm"]))
plt.scatter(df["bill_length_mm"], df["bill_depth_mm"], alpha=0.6)
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.show()
```
