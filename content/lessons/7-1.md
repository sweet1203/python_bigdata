## 실습 전 공통 준비 코드 (복사 실행용)

그래프 예제를 실행하기 전에 아래 셀을 먼저 실행하세요.

```python
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("penguins").dropna()

print("데이터 크기:", df.shape)
df.head()
```

## 1. 왜 데이터를 시각화할까요? 🎨

다음 두 가지를 비교해 봐요:

### 표로 보기
```
Adelie:    152마리
Chinstrap:  68마리
Gentoo:    124마리
```

### 그래프로 보기
```
150 | ####################
100 | #############
 50 | #######
  0 +--Adelie--Chinstrap--Gentoo
```

> 그래프를 보면 "Chinstrap이 제일 적네!"가 한눈에 들어오죠? 이게 바로 **시각화의 힘**이에요!

### 시각화의 장점

| 장점 | 설명 |
|------|------|
| 👁️ **직관적** | 한눈에 패턴이 보임 |
| 🚀 **빠른 이해** | 100개의 숫자보다 그래프 1개가 효과적 |
| 💡 **인사이트 발견** | 숨겨진 규칙 찾기 쉬움 |
| 📊 **설득력** | 발표할 때 효과적 |

## 2. Matplotlib 시작하기 📦

**Matplotlib**(맷플롯립)은 파이썬에서 가장 유명한 **그래프 그리기 라이브러리**예요.

```python
import matplotlib.pyplot as plt
```

---

## 3. 그래프 종류 선택 가이드

| 보고 싶은 것 | 추천 그래프 |
|------------|-------------|
| 데이터의 분포 | 히스토그램 (Histogram) |
| 항목별 비교 | 막대 그래프 (Bar Chart) |
| 두 데이터의 관계 | 산점도 (Scatter Plot) |
| 시간에 따른 변화 | 꺾은선 그래프 (Line Plot) |
| 비율 보기 | 원 그래프 (Pie Chart) |
| 여러 변수 상관관계 | 히트맵 (Heatmap) |

---

## 4. 히스토그램: plt.hist()

데이터의 **분포**를 볼 때 사용해요.

### 실습 1: 펭귄 몸무게 분포

```python
plt.hist(df["body_mass_g"], bins=15, color="skyblue", edgecolor="black")
plt.title("Penguin Body Mass Distribution")
plt.xlabel("body_mass_g")
plt.ylabel("count")
plt.show()
```

`bins`의 의미: 데이터를 몇 개의 구간으로 나눌지 정해요. `bins=15`면 15개의 막대!

### 실습 2: 지느러미 길이 분포

```python
plt.hist(df["flipper_length_mm"], bins=12, color="salmon", edgecolor="black")
plt.title("Flipper Length Distribution")
plt.xlabel("flipper_length_mm")
plt.ylabel("count")
plt.show()
```

---

## 5. 막대 그래프: plt.bar()

**항목별 수량이나 평균**을 비교할 때 사용해요.

### 실습 3: 종별 펭귄 수 (빈도 막대)

```python
df["species"].value_counts().sort_index().plot(kind="bar", color="seagreen")
plt.title("Number of Penguins by Species")
plt.xlabel("species")
plt.ylabel("count")
plt.xticks(rotation=0)
plt.show()
```

### 실습 4: 종별 평균 몸무게 (평균 막대)

```python
df.groupby("species")["body_mass_g"].mean().plot(kind="bar", color="coral")
plt.title("Mean Body Mass by Species")
plt.xlabel("species")
plt.ylabel("mean body_mass_g")
plt.xticks(rotation=0)
plt.show()
```

Gentoo 펭귄이 가장 무겁다는 것을 한눈에 볼 수 있어요!

### 실습 5: 섬별 평균 지느러미 길이

```python
df.groupby("island")["flipper_length_mm"].mean().plot(kind="bar", color="steelblue")
plt.title("Mean Flipper Length by Island")
plt.xlabel("island")
plt.ylabel("mean flipper_length_mm")
plt.xticks(rotation=0)
plt.show()
```

---

## 6. 산점도: plt.scatter()

**두 수치 데이터의 관계**를 볼 때 사용해요.

- 점들이 오른쪽 위로 모이면 -> **양의 상관관계** (같이 증가)
- 점들이 오른쪽 아래로 모이면 -> **음의 상관관계** (반대로 움직임)

### 실습 6: 지느러미 길이 vs 몸무게

```python
plt.scatter(df["flipper_length_mm"], df["body_mass_g"], alpha=0.5)
plt.xlabel("flipper_length_mm")
plt.ylabel("body_mass_g")
plt.title("Flipper Length vs Body Mass")
plt.show()
```

지느러미가 길수록 몸무게도 많이 나가는 경향이 있나요?

### 실습 7: 부리 길이 vs 부리 깊이

```python
plt.scatter(df["bill_length_mm"], df["bill_depth_mm"], alpha=0.5, color="purple")
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.title("Bill Length vs Bill Depth")
plt.show()
```

## 7. 정리하기

### 그래프 종류별 정리

| 그래프 | 함수 | 언제? | penguins 예시 |
|--------|------|-------|--------------|
| 히스토그램 | `plt.hist()` | 분포 | `body_mass_g` 분포 |
| 막대 | `plt.bar()` | 항목 비교 | 종별 마릿수 / 평균 몸무게 |
| 산점도 | `plt.scatter()` | 관계 | 지느러미 vs 몸무게 |

### 그래프 꾸미기 함수

| 함수 | 역할 |
|------|------|
| `plt.title()` | 제목 |
| `plt.xlabel()` | x축 이름 |
| `plt.ylabel()` | y축 이름 |
| `plt.show()` | 화면 출력 |
