# 5차시: 필터링과 그룹화 (조건 & groupby)

> 🎯 **이번 시간 학습 목표**
> - 비교 연산으로 **불리언 마스크**를 만든다.
> - `&` `|` `~`로 조건을 결합한다 (각 조건은 **괄호**).
> - `groupby()`로 종·섬 등 그룹별 통계를 낸다.

**데이터**: **seaborn `penguins`**

---

## 실습 전 공통 준비 코드

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** **`+ 코드`로 셀을 추가**한 뒤, 아래 **단계별 블록**을 순서대로 복사해 실행하세요.

**1단계** — 라이브러리

```python
import pandas as pd
import seaborn as sns
```

**2단계** — 데이터 불러오기 + 앞부분 확인

```python
df = sns.load_dataset("penguins")
df.head()
```

---

## 1. 한 조건 필터

**1단계** — 젠투 종만

```python
df[df["species"] == "Gentoo"]
```

**2단계** — 체중 4500g 초과만

```python
df[df["body_mass_g"] > 4500]
```

---

## 2. 여러 조건 (`&` = 그리고, `|` = 또는)

**1단계** — 체중도 크고 종도 젠투

```python
df[(df["body_mass_g"] > 4500) & (df["species"] == "Gentoo")]
```

**2단계** — 섬이 비스코 **또는** 드림

```python
df[(df["island"] == "Biscoe") | (df["island"] == "Dream")]
```

> ⚠️ `and` 대신 `&`, 각 조건을 `( )`로 묶기.

---

## 3. `isin`

```python
df[df["species"].isin(["Adelie", "Chinstrap"])]
```

---

## 4. `groupby`

**1단계** — 종별 평균 체중

```python
df.groupby("species")["body_mass_g"].mean()
```

**2단계** — 섬별 날개 길이 최댓값

```python
df.groupby("island")["flipper_length_mm"].max()
```

---

## 5. 정리

- 필터: `df[조건]`, 조건 여러 개는 `&` / `|`
- 그룹 집계: `df.groupby(그룹열)[값열].집계함수()`
