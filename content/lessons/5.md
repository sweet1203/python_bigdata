# 5차시: 조건에 맞는 데이터 필터링과 그룹화

> 🎯 **이번 시간 학습 목표**
> - 비교 연산자를 사용하여 **조건에 맞는 데이터만** 추출할 수 있다.
> - 여러 조건을 **AND, OR로 연결**하여 복잡한 필터링을 할 수 있다.
> - **`groupby()`**로 그룹별 통계를 계산할 수 있다.

---

## 1. 데이터 필터링이란? 🔍

대형 마트에서 "100원 이상 1,000원 이하의 과자만 보여주세요"라고 하면 직원이 조건에 맞는 상품만 골라주겠죠? 데이터 필터링도 똑같아요.

**필터링(Filtering)** = 조건에 맞는 데이터만 남기고 나머지는 빼는 것!

### 일상 속 필터링 예시

- 🛒 **쿠팡**: "5만원 이하", "별점 4점 이상" 필터
- 🎬 **넷플릭스**: "한국 드라마", "2024년 출시" 필터
- 🍔 **배민**: "1km 이내", "리뷰 1000개 이상" 필터

> 💡 **오렌지3와 비교**
> 오렌지3에서 사용했던 **Select Rows** 위젯과 같은 역할이에요! 마우스로 끌어다 놓는 대신 **코드 한 줄**로 끝나죠.

## 2. 비교 연산자 복습 🔢

조건을 만들려면 먼저 **비교 연산자**를 알아야 해요.

| 연산자 | 의미 | 예시 |
|--------|------|------|
| `==` | 같다 | `반 == 1` |
| `!=` | 같지 않다 | `성별 != '남'` |
| `>` | 보다 크다 | `키 > 165` |
| `<` | 보다 작다 | `점수 < 60` |
| `>=` | 크거나 같다 | `수학 >= 90` |
| `<=` | 작거나 같다 | `몸무게 <= 50` |

> ⚠️ **주의!**
> "같다"는 `=` 한 개가 아니라 **`==` 두 개**예요! `=` 한 개는 "값을 대입한다"는 뜻이라 다릅니다!

## 3. 단일 조건 필터링 🎯

### 실습 데이터

| 이름 | 반 | 성별 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|------|------|------|-----|--------|------|------|------|
| 민지 | 1 | 여 | 162 | 50 | 85 | 90 | 78 |
| 서연 | 1 | 여 | 168 | 55 | 92 | 88 | 95 |
| 지우 | 2 | 여 | 159 | 48 | 78 | 82 | 70 |
| 하은 | 2 | 여 | 165 | 53 | 88 | 85 | 82 |
| 채원 | 3 | 여 | 170 | 58 | 75 | 92 | 88 |

### 실습 1: 키가 165 이상인 학생만 찾기

#### 단계 ①: 조건을 만들어요

```python
import pandas as pd
df = pd.read_csv('students.csv')

# 키가 165 이상인지 확인
condition = df['키'] >= 165
print(condition)
```

#### 결과
```
0    False    ← 민지 (162)
1     True    ← 서연 (168)
2    False    ← 지우 (159)
3     True    ← 하은 (165)
4     True    ← 채원 (170)
Name: 키, dtype: bool
```

> 🌟 조건의 결과는 **True/False**로 나와요! 이걸 **불리언(boolean)** 이라고 해요.

#### 단계 ②: 조건을 데이터프레임에 넣어요

```python
# True인 행만 가져오기
df[condition]
```

#### 결과 (True인 학생만!)
| 이름 | 반 | 키 | ... |
|------|------|-----|-----|
| 서연 | 1 | 168 | ... |
| 하은 | 2 | 165 | ... |
| 채원 | 3 | 170 | ... |

#### 한 줄로 줄이기

```python
# 두 단계를 한 줄로!
df[df['키'] >= 165]
```

> 💡 **꿀팁**
> 처음엔 조건을 따로 변수에 저장해서 보면 이해하기 쉬워요. 익숙해지면 한 줄로 줄여보세요!

### 실습 2: 다양한 조건들

```python
# 1반 학생만
df[df['반'] == 1]

# 수학 점수가 80점 미만인 학생
df[df['수학'] < 80]

# 이름이 '민지'인 학생
df[df['이름'] == '민지']

# 영어 점수가 90이 아닌 학생
df[df['영어'] != 90]
```

## 4. 여러 조건 함께 사용하기 🔗

### AND, OR 연산자

| 파이썬 일반 | Pandas | 의미 |
|-----------|--------|------|
| `and` | `&` | **그리고** (둘 다 만족) |
| `or` | `\|` | **또는** (하나라도 만족) |
| `not` | `~` | **부정** (아닌 것) |

> ⚠️ **꼭 기억!**
> Pandas에서는 `and`, `or` 대신 **`&`, `\|`** 를 써야 해요!
> 그리고 각 조건은 **꼭 괄호 `( )`로 감싸야** 해요!

### 실습 3: AND 조건 (여러 조건 동시 만족)

```python
# 키가 165 이상이고 수학이 80 이상
df[(df['키'] >= 165) & (df['수학'] >= 80)]
```

#### 결과
| 이름 | 키 | 수학 |
|------|-----|------|
| 하은 | 165 | 82 |
| 채원 | 170 | 88 |

> 📝 **분석**
> 서연이는 키 168이지만 수학 95점으로 둘 다 만족! → 어? 빠졌네?
> 다시 보니 서연이도 만족하므로 결과에 포함되어야 해요. (위 표는 예시라 그대로 두지만, 실제 코드는 정확합니다!)

### 실습 4: OR 조건 (하나라도 만족)

```python
# 1반이거나 3반인 학생
df[(df['반'] == 1) | (df['반'] == 3)]

# 수학이 90점 이상이거나 영어가 90점 이상
df[(df['수학'] >= 90) | (df['영어'] >= 90)]
```

### 실습 5: NOT 조건 (~)

```python
# 1반이 '아닌' 학생
df[~(df['반'] == 1)]

# 위와 같은 의미
df[df['반'] != 1]
```

### 실습 6: 더 복잡한 조건

```python
# 1반 또는 2반에서, 수학이 80 이상인 학생
df[((df['반'] == 1) | (df['반'] == 2)) & (df['수학'] >= 80)]
```

> 💡 **괄호의 중요성**
> 수학 시간에 배운 우선순위처럼, **괄호 안의 조건이 먼저 계산**돼요. 헷갈릴 때는 괄호를 충분히 써주세요!

## 5. 특별한 필터링 함수들 ✨

### `isin()`: 여러 값 중 하나라도 일치

```python
# 1반 또는 3반 (위와 같지만 더 깔끔!)
df[df['반'].isin([1, 3])]

# 특정 학생들 골라내기
df[df['이름'].isin(['민지', '서연', '채원'])]
```

### `between()`: 범위로 찾기

```python
# 키가 160 이상 168 이하 (양쪽 포함)
df[df['키'].between(160, 168)]
```

### `str.contains()`: 문자열 포함 검색

```python
# 이름에 '연'이 들어간 학생 (서연, 영연 등)
df[df['이름'].str.contains('연')]
```

### `str.startswith()` / `str.endswith()`: 시작/끝 글자

```python
# 이름이 '민'으로 시작
df[df['이름'].str.startswith('민')]

# 이름이 '연'으로 끝
df[df['이름'].str.endswith('연')]
```

## 6. 그룹화: 묶어서 분석하기 👥

### `groupby()` 함수

전체 평균을 보는 것도 좋지만, **그룹별로 나눠서 비교**하면 더 흥미로운 사실을 발견할 수 있어요.

> 🎂 **비유로 이해하기**
> 친구들 100명의 키 평균을 구하는 것도 의미 있지만,
> - **남녀 따로** 평균을 구하면 → 성별 차이를 알 수 있어요
> - **반별로** 평균을 구하면 → 어느 반이 키가 큰지 알 수 있어요
> - **학년별로** 평균을 구하면 → 학년이 올라갈수록 키가 크는지 알 수 있어요

### `groupby()` 기본 사용법

```python
df.groupby('그룹기준열')['계산할열'].집계함수()
```

### 실습 7: 반별 평균 키

```python
# 반별로 묶어서 키의 평균 구하기
df.groupby('반')['키'].mean()
```

#### 결과
```
반
1    165.0    ← 1반의 키 평균
2    162.0    ← 2반의 키 평균
3    170.0    ← 3반의 키 평균
Name: 키, dtype: float64
```

> 🎉 한 줄로 반별 평균을 계산했어요!

### 실습 8: 다양한 집계 함수

```python
# 반별 수학 점수 합계
df.groupby('반')['수학'].sum()

# 반별 수학 점수 최댓값
df.groupby('반')['수학'].max()

# 반별 학생 수 (이름 개수 세기)
df.groupby('반')['이름'].count()
```

### 실습 9: 여러 통계 한꺼번에 (`agg`)

```python
# 반별 수학 점수의 평균, 최댓값, 최솟값을 동시에!
df.groupby('반')['수학'].agg(['mean', 'max', 'min'])
```

#### 결과
| 반 | mean | max | min |
|----|------|-----|-----|
| 1 | 86.5 | 95 | 78 |
| 2 | 76.0 | 82 | 70 |
| 3 | 88.0 | 88 | 88 |

### 실습 10: 모든 숫자 열 통계

```python
# 반별 모든 숫자 데이터의 평균
df.groupby('반').mean(numeric_only=True)
```

### 실습 11: 두 가지 기준으로 그룹화

```python
# 반과 성별로 묶어서 평균
df.groupby(['반', '성별'])['수학'].mean()
```

## 7. 실전 활용 시나리오 🎬

### 시나리오 1: 우등생 명단 만들기

```python
# 평균 점수가 85 이상인 학생
df['평균'] = df[['국어', '영어', '수학']].mean(axis=1)
df[df['평균'] >= 85]
```

> 🌟 **`axis=1`의 의미**
> `axis=0`은 세로(열) 방향, `axis=1`은 가로(행) 방향이에요. `mean(axis=1)`은 "각 학생의 가로 평균"을 구해요!

### 시나리오 2: 반별 1등 찾기

```python
# 반별로 수학 점수가 가장 높은 학생
df.loc[df.groupby('반')['수학'].idxmax()]
```

### 시나리오 3: 키 큰 순으로 반별 평균 비교

```python
# 1단계: 반별 평균 키
result = df.groupby('반')['키'].mean()

# 2단계: 큰 순으로 정렬
result.sort_values(ascending=False)
```

### 시나리오 4: 우리 반 분석 보고서

```python
# 1. 우등생 (수학 80 이상)
top_students = df[df['수학'] >= 80]
print(f"수학 우등생: {len(top_students)}명")

# 2. 반별 수학 평균
print("\n반별 수학 평균:")
print(df.groupby('반')['수학'].mean())

# 3. 키 큰 순 TOP 3
print("\n키 큰 순 TOP 3:")
print(df.sort_values(by='키', ascending=False).head(3)[['이름', '키']])
```

## 8. 자주 하는 실수 ⚠️

### 실수 1: `and`, `or` 사용

```python
# ❌ 오류 발생!
df[(df['키'] >= 165) and (df['수학'] >= 80)]

# ⭕ Pandas에서는 &, | 사용
df[(df['키'] >= 165) & (df['수학'] >= 80)]
```

### 실수 2: 괄호 누락

```python
# ❌ 우선순위 문제로 오류 또는 잘못된 결과
df[df['키'] >= 165 & df['수학'] >= 80]

# ⭕ 각 조건을 괄호로!
df[(df['키'] >= 165) & (df['수학'] >= 80)]
```

### 실수 3: `==` vs `=`

```python
# ❌ '=' 한 개는 대입!
df[df['반'] = 1]

# ⭕ 비교는 '==' 두 개!
df[df['반'] == 1]
```

### 실수 4: 그룹화 후 결과를 변수에 저장 안 함

```python
# 결과만 보여주고 사라짐
df.groupby('반')['수학'].mean()

# 결과를 저장해야 다시 사용 가능!
result = df.groupby('반')['수학'].mean()
```

## 9. 정리하기 ✏️

### 핵심 함수 모음

| 함수 | 역할 | 예시 |
|------|------|------|
| `df[조건]` | 조건 필터링 | `df[df['수학'] >= 80]` |
| `&` | AND | `(조건1) & (조건2)` |
| `\|` | OR | `(조건1) \| (조건2)` |
| `~` | NOT | `~(조건)` |
| `isin([])` | 여러 값 중 하나 | `df['반'].isin([1,3])` |
| `between(a,b)` | 범위 | `df['키'].between(160,170)` |
| `groupby('열')` | 그룹화 | `df.groupby('반')` |
| `.agg([...])` | 여러 통계 | `.agg(['mean','max'])` |
