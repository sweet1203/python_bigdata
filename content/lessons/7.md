**데이터**: **seaborn `mpg`** (자동차 연비·실린더·중량 등) — **7차시만** 데이터를 바꿉니다.

---

## 실습 전 공통 준비 코드

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("mpg")
df.head()
```

`origin` 열은 보통 **1=미국, 2=유럽, 3=일본** 같은 정수로 들어 있습니다.

---

## 1. 막대: 지역(origin)별 평균 연비

```python
df.groupby("origin")["mpg"].mean().plot(kind="bar", color="coral")
plt.title("origin별 평균 mpg")
plt.ylabel("평균 연비")
plt.show()
```

---

## 2. 막대: 실린더 수별 평균 연비

```python
df.groupby("cylinders")["mpg"].mean().plot(kind="bar", color="steelblue")
plt.title("실린더 수별 평균 mpg")
plt.ylabel("평균 연비")
plt.show()
```

---

## 3. 산점도: 무게 vs 연비

```python
plt.scatter(df["weight"], df["mpg"], alpha=0.5)
plt.xlabel("weight")
plt.ylabel("mpg")
plt.title("무게와 연비")
plt.show()
```
