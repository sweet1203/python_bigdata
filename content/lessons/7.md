import pandas as pd

`origin` 열은 보통 **1=미국(USA), 2=유럽(Europe), 3=일본(Japan)** 같은 정수로 들어 있습니다.

## 1. 히스토그램 (histogram) — 한 숫자가 어떻게 퍼져 있나?

**언제 쓰나:** 연비·키·점수처럼 **연속적인 숫자 한 열의 분포**(어디에 많이 몰리는지)를 볼 때.

**읽는 법:** 가로축은 값의 구간, 세로축은 그 구간에 들어온 **개수(빈도)**. 막대가 높은 곳 = 그 근처 값이 많다.

```python
plt.hist(df["mpg"], bins=15, color="skyblue", edgecolor="black")
plt.title("Distribution of MPG (miles per gallon)")
plt.xlabel("mpg")
plt.ylabel("count")
plt.show()
```

---

## 2. 막대 그래프 — 범주별 **개수** (`value_counts`)

**언제 쓰나:** 실린더 수·지역 코드처럼 **범주가 몇 번씩 나왔는지**를 막대 길이로 비교할 때.

**읽는 법:** 막대가 길수록 그 범주의 **대수가 많다**.

```python
df["cylinders"].value_counts().sort_index().plot(kind="bar", color="seagreen")
plt.title("Number of cars by cylinder count")
plt.xlabel("cylinders")
plt.ylabel("count")
plt.show()
```

---

## 3. 막대 그래프 — 범주별 **평균** (`groupby` + `mean`)

**언제 쓰나:** 지역·실린더처럼 **그룹을 나눈 뒤**, 숫자(연비 등)의 **평균을 비교**할 때.

**읽는 법:** 막대 높이 = 그 그룹의 **평균 mpg**. 서로 높이를 비교하면 “어느 그룹이 연비가 좋은지”가 보인다.

```python
df.groupby("origin")["mpg"].mean().plot(kind="bar", color="coral")
plt.title("Mean MPG by region (origin code)")
plt.xlabel("origin (1=USA, 2=Europe, 3=Japan)")
plt.ylabel("mean mpg")
plt.show()
```

---

## 4. 막대 그래프 — 실린더 수별 **평균** 연비

**읽는 법:** 실린더가 많을수록 연비가 나빠지는지 같은 **패턴**을 본다.

```python
df.groupby("cylinders")["mpg"].mean().plot(kind="bar", color="steelblue")
plt.title("Mean MPG by number of cylinders")
plt.xlabel("cylinders")
plt.ylabel("mean mpg")
plt.show()
```

---

## 5. 산점도 (scatter plot) — 두 숫자의 **관계**

**언제 쓰나:** “무게가 클수록 연비는?”처럼 **서로 다른 숫자 두 열**이 함께 어떻게 움직이는지 볼 때.

**읽는 법:** 오른쪽 위로 점이 몰리면 **둘 다 큰 경향**, 오른쪽 아래로 내려가면 **하나는 커질 때 다른 하나는 작아지는 경향**이다.

```python
plt.scatter(df["weight"], df["mpg"], alpha=0.5)
plt.xlabel("weight")
plt.ylabel("mpg")
plt.title("MPG vs vehicle weight")
plt.show()
```

---

## 6. 선 그래프 (line chart) — **순서**가 있는 축의 변화

**언제 쓰나:** 연식·월·시간처럼 **순서가 의미 있을 때**, 평균 등의 **추세**를 볼 때.

**읽는 법:** 선이 **오르면** 그 연도에 평균 연비가 좋아진 것, **내리면** 나빠진 것으로 읽는다.

```python
df.groupby("model_year")["mpg"].mean().plot(kind="line", marker="o", color="purple")
plt.title("Mean MPG by model year")
plt.xlabel("model_year")
plt.ylabel("mean mpg")
plt.grid(True, alpha=0.3)
plt.show()
```

---

## 7. 히트맵 (heatmap) — 숫자들끼리 **얼마나 같이 움직이나** (상관)

**언제 쓰나:** 연비·배기량·무게처럼 **숫자 열이 여러 개**일 때, **상관계수**를 색으로 한눈에 보고 싶을 때.

**읽는 법:** 색이 진할수록 **강한 상관**. 보통 **빨간 쪽은 함께 커지는 방향**, **파란 쪽은 한쪽이 커지면 다른 쪽은 작아지는 방향**(색 스케일은 `cmap`에 따라 다를 수 있음). **대각선은 자기 자신과의 상관이라 항상 1**이다.

```python
num_cols = ["mpg", "cylinders", "displacement", "horsepower", "weight", "acceleration", "model_year"]
sub = df[num_cols].dropna()
plt.figure(figsize=(9, 7))
sns.heatmap(sub.corr(), annot=True, fmt=".2f", cmap="RdBu_r", center=0, linewidths=0.5)
plt.title("Correlation heatmap (numeric columns in mpg)")
plt.show()
```

> `horsepower`에 결측이 있으면 `dropna()`로 그 행을 빼고 상관을 계산합니다. 실무에서는 결측 처리 방법을 먼저 정합니다.

---

## 8. 파이 그래프 (pie chart) — **전체 중 비율**

**언제 쓰나:** 지역·응답 유형처럼 **범주가 적고(대략 2~7개)**, “전체 100% 중 몇 %인가?”를 **비율**로 보여 주고 싶을 때.

**읽는 법:** 조각이 클수록 그 범주의 **비중이 크다**. 퍼센트 숫자(`autopct`)와 **범례(라벨)**를 같이 본다.

**주의:** 범주가 너무 많으면 조각이 잘게 쪼개져 읽기 어렵다. 그럴 때는 **막대(개수)**가 더 낫다.

```python
origin_map = {1: "USA", 2: "Europe", 3: "Japan"}
region = df["origin"].map(origin_map)
counts = region.value_counts()
plt.figure(figsize=(6, 6))
plt.pie(counts, labels=counts.index, autopct="%1.1f%%", startangle=90)
plt.title("Share of cars by region (origin)")
plt.ylabel("")
plt.axis("equal")
plt.show()
```

---

## 9. 정리 — 어떤 그래프를 언제 쓸까

| 그래프 | 주로 쓰는 상황 | 출력에서 집중할 것 |
|--------|----------------|---------------------|
| **히스토그램** | 숫자 한 열의 **분포**(어디에 몰리는지) | 봉우리 위치, 긴 꼬리 여부 |
| **막대 (빈도)** | 범주별 **개수** 비교 | 막대 길이 순위 |
| **막대 (평균 등)** | 범주별 **요약값**(평균·합계) 비교 | 어느 그룹이 더 큰지 |
| **산점도** | 숫자 **두 열의 관계** | 점 구름의 방향(대각선 패턴) |
| **선 그래프** | **순서 있는 축**에서의 추세 | 오름·내림, 변곡 |
| **히트맵 (상관)** | 숫자 여러 열의 **서로의 상관** | 진한 칸 쌍, 해석 시 인과 주의 |
| **파이** | 범주가 적을 때 **비율(점유율)** | %, 전체 대비 몫 |

**한 줄 팁:** “무엇을 비교·설명하려는가?”를 먼저 정한 뒤, 위 표에서 **그 목적에 맞는 그래프 하나**를 고르면 된다.

### 💪 도전 과제

mpg 데이터로 다음 그래프를 직접 그려보세요!  
(수업 코드를 참고하되, 열 이름과 색을 바꿔 스스로 완성해 보아요)

```python
# 준비 코드 (이미 실행했다면 생략)
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
df = sns.load_dataset(“mpg”)

# 문제 1. horsepower(마력) 분포를 히스토그램으로 그리기
#         bins=10, 색깔은 'orange'로 설정
plt.hist(df[“horsepower”].dropna(), bins=10, color=”orange”, edgecolor=”black”)
plt.title(“Distribution of Horsepower”)
plt.xlabel(“horsepower”)
plt.ylabel(“count”)
plt.show()

# 문제 2. 실린더 수(cylinders)별 평균 마력(horsepower)을 가로 막대(barh)로 그리기
df.groupby(“cylinders”)[“horsepower”].mean().dropna().plot(kind=”barh”, color=”steelblue”)
plt.title(“Mean Horsepower by Cylinders”)
plt.xlabel(“mean horsepower”)
plt.show()

# 문제 3. 연식(model_year)별 평균 무게(weight) 변화를 선 그래프로 그리기
df.groupby(“model_year”)[“weight”].mean().plot(kind=”line”, marker=”o”, color=”green”)
plt.title(“Mean Weight by Model Year”)
plt.xlabel(“model_year”)
plt.ylabel(“mean weight”)
plt.grid(True, alpha=0.3)
plt.show()
```

> 💡 **`kind='barh'`** 에서 `h`는 horizontal(가로)이에요. `kind='bar'`(세로)와 방향이 반대예요!
