## 1. 왜 데이터를 시각화할까요? 🎨

다음 두 가지를 비교해 봐요:

### 표로 보기
```
Adelie:    152마리
Chinstrap:  68마리
Gentoo:    124마리
```

### 그래프로 보기
```
150 ┤ ██████████████████
100 ┤ ████████████
 50 ┤ ███████
  0 └──Adelie─Chinstrap─Gentoo
```

> 🤔 **어느 쪽이 더 잘 이해되나요?**
> 그래프를 보면 "**오! Chinstrap이 제일 적네!**"가 한눈에 들어오죠? 이게 바로 **시각화의 힘**이에요!

### 시각화의 장점

| 장점 | 설명 |
|------|------|
| 👁️ **직관적** | 한눈에 패턴이 보임 |
| 🚀 **빠른 이해** | 100개의 숫자보다 그래프 1개가 효과적 |
| 💡 **인사이트 발견** | 숨겨진 규칙 찾기 쉬움 |
| 📊 **설득력** | 발표할 때 효과적 |

## 4. 히스토그램: `plt.hist()` 📉

### 언제 사용하나요?
- 📊 **데이터의 분포**를 볼 때 (키 분포, 점수 분포, 몸무게 분포)

### 실습 1: 펭귄 몸무게 분포

```python
plt.hist(df["body_mass_g"], bins=15, color="skyblue", edgecolor="black")
plt.title("Penguin Body Mass Distribution")
plt.xlabel("body_mass_g")
plt.ylabel("count")
plt.show()
```

> 💡 **`bins`의 의미**
> 데이터를 몇 개의 **구간**으로 나눌지 정해요. `bins=15`면 15개의 막대로!

### 실습 2: 지느러미 길이 분포

```python
plt.hist(df["flipper_length_mm"], bins=12, color="salmon", edgecolor="black")
plt.title("Flipper Length Distribution")
plt.xlabel("flipper_length_mm")
plt.ylabel("count")
plt.show()
```

---

## 5. 막대 그래프: `plt.bar()` 📊

### 언제 사용하나요?
- 🏷️ **항목별 수량이나 평균을 비교**할 때

### 실습 3: 종별 펭귄 수 (빈도 막대)

```python
df["species"].value_counts().sort_index().plot(kind="bar", color="seagreen")
plt.title("Number of Penguins by Species")
plt.xlabel("species")
plt.ylabel("count")
plt.xticks(rotation=0)
plt.show()
```

### 실습 4: 종별 평균 몸무게 (평균 막대)

```python
df.groupby("species")["body_mass_g"].mean().plot(kind="bar", color="coral")
plt.title("Mean Body Mass by Species")
plt.xlabel("species")
plt.ylabel("mean body_mass_g")
plt.xticks(rotation=0)
plt.show()
```

> 🌟 **비교 포인트**: Gentoo 펭귄이 가장 무겁다는 것을 한눈에 볼 수 있어요!

### 실습 5: 섬별 평균 지느러미 길이

```python
df.groupby("island")["flipper_length_mm"].mean().plot(kind="bar", color="steelblue")
plt.title("Mean Flipper Length by Island")
plt.xlabel("island")
plt.ylabel("mean flipper_length_mm")
plt.xticks(rotation=0)
plt.show()
```

## 6. 산점도: `plt.scatter()` 🔵

### 언제 사용하나요?
- 🔗 **두 수치 데이터의 관계**를 볼 때
- 점들이 오른쪽 위로 모이면 → **양의 상관관계** (같이 증가)
- 점들이 오른쪽 아래로 모이면 → **음의 상관관계** (반대로 움직임)

### 실습 6: 지느러미 길이 vs 몸무게

```python
plt.scatter(df["flipper_length_mm"], df["body_mass_g"], alpha=0.5)
plt.xlabel("flipper_length_mm")
plt.ylabel("body_mass_g")
plt.title("Flipper Length vs Body Mass")
plt.show()
```

> 🤔 **분석**: 지느러미가 길수록 몸무게도 많이 나가는 경향이 있나요?

### 실습 7: 부리 길이 vs 부리 깊이

```python
plt.scatter(df["bill_length_mm"], df["bill_depth_mm"], alpha=0.5, color="purple")
plt.xlabel("bill_length_mm")
plt.ylabel("bill_depth_mm")
plt.title("Bill Length vs Bill Depth")
plt.show()
```

## 7. 꺾은선 그래프: `plt.plot()` 📈

### 언제 사용하나요?
- ⏰ **시간에 따른 변화**나 **순서가 있는 데이터**를 볼 때

### 실습 8: 섬별 평균 몸무게 (꺾은선)

```python
df.groupby("island")["body_mass_g"].mean().plot(kind="line", marker="o", color="darkorange")
plt.title("Mean Body Mass by Island")
plt.xlabel("island")
plt.ylabel("mean body_mass_g")
plt.grid(True, alpha=0.3)
plt.show()
```

### 실습 9: 그래프 꾸미기

```python
월 = ["1월", "2월", "3월", "4월", "5월", "6월"]
기온 = [-2, 1, 6, 13, 18, 22]

plt.plot(월, 기온,
         color="red",
         marker="o",
         linestyle="--",
         linewidth=2,
         label="평균 기온")

plt.title("월별 평균 기온", fontsize=15)
plt.xlabel("월")
plt.ylabel("기온 (°C)")
plt.legend()
plt.grid(True)
plt.show()
```

> 🌟 **꺾은선의 장점**: 시간축이 있는 데이터(기온, 주가, 인구 변화)에 가장 잘 맞아요!

## 8. 원 그래프(파이 차트): `plt.pie()` 🥧

### 언제 사용하나요?
- 🍰 **전체에서 각 항목의 비율**을 보여줄 때

### 실습 10: 종별 펭귄 비율

```python
counts = df["species"].value_counts()
plt.figure(figsize=(6, 6))
plt.pie(counts, labels=counts.index, autopct="%1.1f%%", startangle=90)
plt.title("Share of Penguins by Species")
plt.show()
```

> 💡 **`autopct='%1.1f%%'`의 의미**
> 각 조각에 **비율(%)** 을 자동으로 표시해줘요!

### 실습 11: 섬별 비율 + 한 조각 강조

```python
island_counts = df["island"].value_counts()
explode = [0.1, 0, 0]   # 첫 번째 조각(가장 많은 섬)을 살짝 떼어내기

plt.figure(figsize=(6, 6))
plt.pie(island_counts, labels=island_counts.index,
        autopct="%1.1f%%", explode=explode, shadow=True, startangle=90)
plt.title("Share of Penguins by Island")
plt.show()
```

## 9. 히트맵 🌡️

### 언제 사용하나요?
- 📐 **여러 수치 변수들 사이의 상관관계**를 한눈에 볼 때
- 값이 **1에 가까울수록** 강한 양의 상관, **-1에 가까울수록** 강한 음의 상관

### 실습 12: 펭귄 수치 데이터 상관관계

```python
num_cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]
corr = df[num_cols].corr()

plt.figure(figsize=(7, 5))
import seaborn as sns
sns.heatmap(corr, annot=True, fmt=".2f", cmap="RdBu_r", center=0, linewidths=0.5)
plt.title("Correlation Heatmap (penguins numeric columns)")
plt.show()
```

> 🤔 **읽는 법**: `flipper_length_mm`과 `body_mass_g`의 상관계수가 높으면?
> → "지느러미가 길수록 몸무게도 많이 나간다"는 경향이 강하다는 뜻!

## 10. 여러 그래프 한 번에 그리기 (서브플롯) 🖼️

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# 1번: 히스토그램
axes[0, 0].hist(df["body_mass_g"], bins=12, color="skyblue", edgecolor="black")
axes[0, 0].set_title("Body Mass Distribution")

# 2번: 막대 그래프
df["species"].value_counts().sort_index().plot(ax=axes[0, 1], kind="bar", color="seagreen")
axes[0, 1].set_title("Count by Species")
axes[0, 1].tick_params(axis="x", rotation=0)

# 3번: 산점도
axes[1, 0].scatter(df["flipper_length_mm"], df["body_mass_g"], alpha=0.5)
axes[1, 0].set_title("Flipper vs Body Mass")

# 4번: 파이 차트
counts = df["species"].value_counts()
axes[1, 1].pie(counts, labels=counts.index, autopct="%1.1f%%")
axes[1, 1].set_title("Species Share")

plt.tight_layout()
plt.show()
```

```python
x = [1, 2, 3]
y = [10, 20]      # 길이가 달라서 오류!
plt.plot(x, y)

y = [10, 20, 30]  # ✅ 같은 길이로
```
