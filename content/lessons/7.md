## 1. 왜 데이터를 시각화할까요? 🎨

다음 두 가지를 비교해 봐요:

### 표로 보기
```
1월: 12,500
2월: 13,200
3월: 15,800
4월: 19,500
5월: 22,100
6월: 24,800
```

### 그래프로 보기
```
25000 ┤                    ╱
20000 ┤                ╱
15000 ┤        ╭──╯
10000 ┤  ─────╯
      └──┬──┬──┬──┬──┬──┬──
         1월 2월 3월 4월 5월 6월
```

> 🤔 **어느 쪽이 더 잘 이해되나요?**
> 그래프를 보면 "**오! 점점 늘고 있네!**"가 한눈에 들어오죠? 이게 바로 **시각화의 힘**이에요!

### 시각화의 장점

| 장점 | 설명 |
|------|------|
| 👁️ **직관적** | 한눈에 패턴이 보임 |

| 💡 **인사이트 발견** | 숨겨진 규칙 찾기 쉬움 |
| 📊 **설득력** | 발표할 때 효과적 |

> 💬 **명언**
> "한 장의 그림은 천 마디 말의 가치가 있다." - 이 말은 **데이터 시각화에도 그대로** 적용돼요!

## 4. 꺾은선 그래프: `plt.plot()` 📈

### 언제 사용하나요?
- ⏰ **시간에 따른 변화**를 볼 때
- 🌡️ 기온 변화, 인구 변화, 주가 변화

### 실습 1: 월별 평균 기온 그리기

```python
import matplotlib.pyplot as plt

# 데이터 준비
월 = ['1월', '2월', '3월', '4월', '5월', '6월']
기온 = [-2, 1, 6, 13, 18, 22]

# 꺾은선 그래프 그리기
plt.plot(월, 기온)

# 그래프 보여주기 (꼭 필요!)
plt.show()
```

### 실습 2: 그래프 꾸미기

```python
plt.plot(월, 기온, 
         color='red',         # 선 색깔
         marker='o',          # 점 모양 (동그라미)
         linestyle='--',      # 선 모양 (점선)
         linewidth=2,         # 선 굵기
         label='평균 기온')   # 범례 이름

plt.title('월별 평균 기온', fontsize=15)   # 제목
plt.xlabel('월')                          # x축 이름
plt.ylabel('기온 (°C)')                   # y축 이름
plt.legend()                              # 범례 표시
plt.grid(True)                            # 격자 표시
plt.show()
```

### 색깔과 모양 선택지

#### 자주 쓰는 색깔
| 코드 | 색깔 |
|------|------|
| `'red'` 또는 `'r'` | 🔴 빨강 |
| `'blue'` 또는 `'b'` | 🔵 파랑 |
| `'green'` 또는 `'g'` | 🟢 초록 |
| `'black'` 또는 `'k'` | ⚫ 검정 |
| `'#FF6B9D'` | 핑크 (HEX 코드) |

#### 마커(점 모양)
| 코드 | 모양 |
|------|------|
| `'o'` | 동그라미 |
| `'s'` | 네모 |
| `'^'` | 위쪽 삼각형 |
| `'*'` | 별 |
| `'D'` | 다이아몬드 |

#### 선 스타일
| 코드 | 모양 |
|------|------|
| `'-'` | 실선 |
| `'--'` | 점선 |
| `':'` | 도트 |
| `'-.'` | 일점쇄선 |

### 실습 3: 두 개의 선 함께 그리기

```python
민지점수 = [85, 88, 92, 87, 90]
서연점수 = [78, 82, 85, 80, 88]
시험 = ['1차', '2차', '3차', '4차', '5차']

plt.plot(시험, 민지점수, marker='o', label='민지')
plt.plot(시험, 서연점수, marker='s', label='서연')

plt.title('민지 vs 서연 점수 비교')
plt.xlabel('시험 차수')
plt.ylabel('점수')
plt.legend()
plt.show()
```

## 5. 막대 그래프: `plt.bar()` 📊

### 언제 사용하나요?
- 🏷️ **항목별 비교**할 때
- 📚 과목별 점수, 반별 인원

### 실습 4: 과목별 평균 점수

```python
과목 = ['국어', '영어', '수학', '과학', '사회']
점수 = [85, 88, 76, 92, 80]

plt.bar(과목, 점수, color='skyblue')
plt.title('우리 반 과목별 평균 점수')
plt.xlabel('과목')
plt.ylabel('점수')
plt.ylim(0, 100)   # y축 범위 설정 (0~100점)
plt.show()
```

### 실습 5: 가로 막대 그래프

```python
# barh: 가로 막대 그래프
plt.barh(과목, 점수, color='lightcoral')
plt.title('과목별 점수 (가로)')
plt.xlabel('점수')
plt.ylabel('과목')
plt.show()
```

> 🌟 **`barh`의 'h'는 horizontal(가로)** 의 첫 글자예요!

### 실습 6: 색깔 다양하게

```python
색깔리스트 = ['red', 'orange', 'gold', 'green', 'blue']
plt.bar(과목, 점수, color=색깔리스트)
plt.title('알록달록 과목별 점수')
plt.show()
```

### 실습 7: 막대 위에 숫자 표시

```python
plt.bar(과목, 점수, color='skyblue')

# 각 막대 위에 점수 쓰기
for i, v in enumerate(점수):
    plt.text(i, v + 1, str(v), ha='center', fontsize=12)

plt.title('과목별 점수 (숫자 표시)')
plt.ylim(0, 100)
plt.show()
```

## 6. 원 그래프(파이 차트): `plt.pie()` 🥧

### 언제 사용하나요?
- 🍰 **전체에서 차지하는 비율**을 보여줄 때
- 📊 MBTI 분포, 좋아하는 음식 비율

### 실습 8: 우리 반 좋아하는 과목 비율

```python
과목 = ['수학', '영어', '국어', '과학', '체육']
인원 = [5, 8, 6, 4, 12]

plt.pie(인원, labels=과목, autopct='%1.1f%%')
plt.title('좋아하는 과목 비율')
plt.show()
```

> 💡 **`autopct='%1.1f%%'`의 의미**
> 각 조각에 **비율(%)** 을 자동으로 표시해줘요. 1.1f는 "소수점 1자리까지"라는 뜻!

### 실습 9: 한 조각 강조하기

```python
explode = [0, 0, 0, 0, 0.1]  # 마지막(체육) 조각만 0.1만큼 떨어뜨림

plt.pie(인원, labels=과목, autopct='%1.1f%%', 
        explode=explode, shadow=True)
plt.title('좋아하는 과목 (체육 강조!)')
plt.show()
```

## 7. 산점도: `plt.scatter()` 🔵

### 언제 사용하나요?
- 🔗 **두 데이터의 관계**를 볼 때
- 📐 키와 몸무게의 관계, 공부 시간과 성적의 관계

### 실습 10: 키와 몸무게의 관계

```python
키 = [162, 168, 159, 165, 170, 158, 172, 160]
몸무게 = [50, 55, 48, 53, 58, 47, 62, 51]

plt.scatter(키, 몸무게, color='purple', s=100)
plt.title('키와 몸무게의 관계')
plt.xlabel('키 (cm)')
plt.ylabel('몸무게 (kg)')
plt.grid(True)
plt.show()
```

> 💡 **`s=100`의 의미**
> 점의 **크기(size)**를 100으로 설정해요. 숫자를 키울수록 점이 커져요!

### 실습 11: 점 크기와 색깔 다르게

```python
import numpy as np

키 = [162, 168, 159, 165, 170]
몸무게 = [50, 55, 48, 53, 58]
점수 = [85, 92, 78, 88, 95]   # 점수에 따라 색깔
공부시간 = [50, 80, 30, 60, 90]  # 공부시간에 따라 점 크기

plt.scatter(키, 몸무게, 
            s=공부시간*5,    # 공부 많이 한 학생일수록 큰 점
            c=점수,           # 점수에 따라 색깔
            cmap='viridis',   # 색깔 테마
            alpha=0.7)        # 투명도

plt.colorbar(label='점수')
plt.title('키, 몸무게, 점수, 공부시간 한 번에!')
plt.xlabel('키 (cm)')
plt.ylabel('몸무게 (kg)')
plt.show()
```

> 🎨 **고급 기법!**
> 점 하나에 **여러 정보**를 담을 수 있어요. 위치(x,y) + 크기 + 색깔 = **4가지 정보**를 한 그래프에!

## 8. 히스토그램: `plt.hist()` 📉

### 언제 사용하나요?
- 📊 **데이터의 분포**를 볼 때
- 🎯 점수 분포, 키 분포 등

점수들 = [65, 72, 78, 85, 88, 90, 92, 75, 80, 95,

## 9. Pandas로 바로 그래프 그리기 🐼

판다스 데이터프레임에서 **`.plot()`** 으로 직접 그래프를 그릴 수 있어요!

```python
import pandas as pd

df = pd.read_csv('students.csv')

# 막대 그래프
df['수학'].plot(kind='bar')

# 꺾은선
df['수학'].plot(kind='line')

# 히스토그램
df['수학'].plot(kind='hist')

# 박스 플롯
df['수학'].plot(kind='box')

plt.show()
```

### `kind` 옵션 종류
| kind | 의미 |
|------|------|
| `'line'` | 꺾은선 |
| `'bar'` | 세로 막대 |
| `'barh'` | 가로 막대 |
| `'hist'` | 히스토그램 |
| `'box'` | 박스 플롯 |
| `'pie'` | 원 그래프 |
| `'scatter'` | 산점도 |

### 실습 13: 판다스로 그룹별 평균 그래프

```python
# 반별 수학 평균을 막대 그래프로!
df.groupby('반')['수학'].mean().plot(kind='bar', color='skyblue')
plt.title('반별 수학 평균')
plt.xlabel('반')
plt.ylabel('평균 점수')
plt.xticks(rotation=0)   # x축 글자 회전 안 하기
plt.show()
```

## 10. 여러 그래프 한 번에 그리기 (서브플롯) 🖼️

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# 1번 자리 (왼쪽 위)
axes[0, 0].plot([1, 2, 3, 4], [10, 20, 25, 30])
axes[0, 0].set_title('꺾은선')

# 2번 자리 (오른쪽 위)
axes[0, 1].bar(['A', 'B', 'C'], [3, 7, 5])
axes[0, 1].set_title('막대')

# 3번 자리 (왼쪽 아래)
axes[1, 0].scatter([1, 2, 3], [4, 5, 6])
axes[1, 0].set_title('산점도')

# 4번 자리 (오른쪽 아래)
axes[1, 1].pie([3, 5, 2], labels=['A', 'B', 'C'])
axes[1, 1].set_title('원 그래프')

plt.tight_layout()  # 그래프끼리 안 겹치게
plt.show()
```
