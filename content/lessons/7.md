> - `value_counts`·`groupby` 결과를 차트와 연결한다.
> - 제목·축 이름을 붙여 그림을 마무리한다.

**데이터**: **seaborn `mpg`** (자동차 연비·실린더·연식 등) — **7차시만** 데이터를 바꿉니다.

---

## 실습 전 공통 준비 코드

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = sns.load_dataset("mpg")
df.head()
```

`origin` 열은 보통 **1=미국, 2=유럽, 3=일본** 같은 정수로 들어 있습니다.

---

## 1. 히스토그램 — 연비(mpg)가 어떻게 퍼져 있나? 📊

**한 열의 분포**를 볼 때 가장 단순한 그래프입니다. `bins`는 막대 개수(구간 나누기)예요.

```python
plt.hist(df["mpg"], bins=15, color="skyblue", edgecolor="black")
plt.title("연비(mpg) 분포")
plt.xlabel("mpg")
plt.ylabel("대수(빈도)")
plt.show()
```

---

## 2. 막대 — 실린더 수가 몇 대씩 있나? (개수 세기)

`groupby` 없이 **빈도만** 세면 됩니다. 코드가 짧아서 부담이 적어요.

```python
df["cylinders"].value_counts().sort_index().plot(kind="bar", color="seagreen")
plt.title("실린더 수별 자동차 대수")
plt.xlabel("cylinders")
plt.ylabel("대수")
plt.show()
```

---

## 3. 막대 — 지역(origin)별 **평균** 연비

```python
df.groupby("origin")["mpg"].mean().plot(kind="bar", color="coral")
plt.title("origin별 평균 mpg")
plt.ylabel("평균 연비")
plt.show()
```

---

## 4. 막대 — 실린더 수별 **평균** 연비

```python
df.groupby("cylinders")["mpg"].mean().plot(kind="bar", color="steelblue")
plt.title("실린더 수별 평균 mpg")
plt.ylabel("평균 연비")
plt.show()
```

---

## 5. 산점도 — 무게와 연비 관계

```python
plt.scatter(df["weight"], df["mpg"], alpha=0.5)
plt.xlabel("weight")
plt.ylabel("mpg")
plt.title("무게와 연비")
plt.show()
```

---

## 6. 선 그래프 — 연식(model_year)별 평균 연비 추이

점을 찍고 선으로 이어 **추세**를 보기 좋습니다.

```python
df.groupby("model_year")["mpg"].mean().plot(kind="line", marker="o", color="purple")
plt.title("연식별 평균 연비 추이")
plt.xlabel("model_year")
plt.ylabel("평균 mpg")
plt.grid(True, alpha=0.3)
plt.show()
```

## 8. 정리

| 그래프 | 언제 쓰기 좋을까 |
|--------|------------------|
| **히스토그램** | 한 수치 열의 **분포** |
| **막대 (value_counts)** | 범주별 **개수** 비교 |
| **막대 (groupby 평균)** | 범주별 **평균** 비교 |
| **산점도** | 두 수치의 **관계** |
| **선 그래프** | 순서 있는 축(연도 등)의 **변화** |
