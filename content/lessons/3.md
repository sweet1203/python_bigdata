# 3차시: 데이터 정렬과 기초 통계 파악하기

> 🎯 **이번 시간 학습 목표**
> - `sort_values()`로 오름차순/내림차순 정렬한다.
> - `describe()`로 숫자 열의 기초 통계를 본다.
> - `value_counts()`·`unique()`로 범주형(`species`, `island` 등)을 분석한다.

**데이터**: **seaborn `penguins`** (1~2차시와 동일)

---

## 실습 전 공통 준비 코드

> 📎 **한 파일 제출:** **맨 위 셀**에만 아래 `import`와 `load_dataset`을 두고, 아래 절의 코드에는 **`import`를 반복하지 않습니다.**

```python
import pandas as pd
import seaborn as sns

df = sns.load_dataset("penguins")
print("데이터 크기:", df.shape)
df.head()
```

---

## 1. `sort_values()`

```python
df.sort_values(by="bill_length_mm", ascending=False)  # 부리 길이 긴 순
df.sort_values(by="body_mass_g", ascending=True)      # 체중 가벼운 순
```

| 매개변수 | 의미 |
|---------|------|
| `by` | 기준 열 이름 |
| `ascending=True` | 오름차순 (작은 값 → 큰 값) |
| `ascending=False` | 내림차순 (큰 값 → 작은 값) |

상위 3마리만 보려면:

```python
df.sort_values(by="flipper_length_mm", ascending=False).head(3)
```

---

## 2. `describe()`

숫자 열에 대해 count, mean, std, min, max, 사분위 등을 한 번에 봅니다.

```python
df.describe()
```

---

## 3. 범주형: `value_counts()`, `unique()`

```python
df["species"].value_counts()
df["island"].value_counts()
df["species"].unique()
```

종별 마리 수, 섬별 마리 수를 빠르게 셀 수 있어요.

---

## 4. 정리

- 정렬: `sort_values(by=..., ascending=...)`
- 수치 요약: `describe()`
- 범주 빈도: `value_counts()`
