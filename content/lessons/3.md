## 1. `sort_values()`

**1단계** — 부리 길이 긴 순(내림차순)

```python
df.sort_values(by="bill_length_mm", ascending=False)
```

**2단계** — 체중 가벼운 순(오름차순)

```python
df.sort_values(by="body_mass_g", ascending=True)
```

| 매개변수 | 의미 |
|---------|------|
| `by` | 기준 열 이름 |
| `ascending=True` | 오름차순 (작은 값 → 큰 값) |
| `ascending=False` | 내림차순 (큰 값 → 작은 값) |

상위 3마리만 보려면:

```python
df.sort_values(by="flipper_length_mm", ascending=False).head(3)
```

---

## 2. `describe()`

숫자 열에 대해 count, mean, std, min, max, 사분위 등을 한 번에 봅니다.

```python
df.describe()
```

---

## 3. 범주형: `value_counts()`, `unique()`

**1단계** — 종별 마리 수

```python
df["species"].value_counts()
```

**2단계** — 섬별 마리 수

```python
df["island"].value_counts()
```

**3단계** — 종 이름이 어떤 값들인지(중복 없이)

```python
df["species"].unique()
```

종별 마리 수, 섬별 마리 수를 빠르게 셀 수 있어요.

---

## 4. 정리

- 정렬: `sort_values(by=..., ascending=...)`
- 수치 요약: `describe()`
- 범주 빈도: `value_counts()`
