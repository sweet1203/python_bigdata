## 1. 왜 데이터를 정렬할까요? 🏆

올림픽 메달 순위표를 떠올려 볼까요? 만약 메달 표가 나라 이름순으로 마구잡이로 섞여 있다면 어디가 1등인지 한눈에 파악하기 어려워요. 

데이터를 **정렬**하면:
- 🥇 **1등이 누구인지** 바로 알 수 있어요.
- 📈 **순위와 패턴**이 보여요.
- 🎯 **상위/하위 그룹**을 쉽게 분리할 수 있어요.

> 🍳 **일상 속 정렬**
> - 인스타 인기 게시물 → 좋아요 많은 순
> - 유튜브 인기 동영상 → 조회수 많은 순
> - 멜론 차트 → 청취자 수 많은 순
> 
> 이 모든 게 **데이터 정렬**의 결과예요!

## 2. 정렬 함수 `sort_values()` 사용법 🔢

### 기본 사용법

```python
df.sort_values(by='기준열', ascending=True/False)
```

| 매개변수 | 의미 |
|---------|------|
| `by` | **무엇을 기준**으로 정렬할지 (열 이름) |
| `ascending=True` | **오름차순** (작은 값 → 큰 값) ⬆️ |
| `ascending=False` | **내림차순** (큰 값 → 작은 값) ⬇️ |

> 📝 **단어 외우기 팁**
> - **as**cending = a, s, c (영어 알파벳 순서) → 작은 값부터
> - **de**scending = de(descend, 내려가다) → 큰 값부터

### 실습 1: 수학 점수 높은 순 정렬

가상의 학생 데이터로 실습해 봅시다.

| 이름 | 반 | 성별 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|------|------|------|-----|--------|------|------|------|
| 민지 | 1 | 여 | 162 | 50 | 85 | 90 | 78 |
| 서연 | 1 | 여 | 168 | 55 | 92 | 88 | 95 |
| 지우 | 2 | 여 | 159 | 48 | 78 | 82 | 70 |
| 하은 | 2 | 여 | 165 | 53 | 88 | 85 | 82 |
| 채원 | 3 | 여 | 170 | 58 | 75 | 92 | 88 |

```python
import pandas as pd
df = pd.read_csv('students.csv')

# 수학 점수 높은 순으로 정렬 (내림차순)
df.sort_values(by='수학', ascending=False)
```

#### 실행 결과
| 이름 | 수학 |
|------|------|
| 서연 | 95 |
| 채원 | 88 |
| 하은 | 82 |
| 민지 | 78 |
| 지우 | 70 |

> 🎉 와! 수학 1등은 서연이네요!

### 실습 2: 키 작은 순 정렬

```python
# 키 작은 순으로 정렬 (오름차순)
df.sort_values(by='키', ascending=True)

# ascending은 기본값이 True라서 생략 가능!
df.sort_values(by='키')
```

### 실습 3: 두 가지 기준으로 정렬하기

만약 **반별로 묶고**, **각 반에서 수학 점수 높은 순**으로 보고 싶다면?

```python
# 1순위: 반 (오름차순), 2순위: 수학 (내림차순)
df.sort_values(by=['반', '수학'], ascending=[True, False])
```

> 💡 **포인트**
> 여러 기준으로 정렬할 때는 **리스트 `[ ]`** 로 감싸서 전달해요!

### 실습 4: 상위 3등만 뽑기

정렬 + `head()`를 조합하면 상위 N등을 쉽게 뽑을 수 있어요.

```python
# 키 큰 순서대로 상위 3명만!
df.sort_values(by='키', ascending=False).head(3)
```

이걸 **메서드 체이닝(Method Chaining)** 이라고 해요. 점(`.`)으로 함수를 연결해서 한 줄로 쓰는 마법이죠! ✨

## 3. 숫자 데이터의 기초 통계 `describe()` 📊

### `describe()` 함수란?

`describe()`는 데이터의 **요약 정보를 한 번에** 보여주는 마법 같은 함수예요.

```python
df.describe()
```

#### 실행 결과 예시

|   | 반 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|---|-----|-----|--------|------|------|------|
| **count** | 5.0 | 5.0 | 5.0 | 5.0 | 5.0 | 5.0 |
| **mean** | 1.8 | 164.8 | 52.8 | 83.6 | 87.4 | 82.6 |
| **std** | 0.8 | 4.4 | 3.8 | 6.7 | 3.9 | 9.5 |
| **min** | 1.0 | 159.0 | 48.0 | 75.0 | 82.0 | 70.0 |
| **25%** | 1.0 | 162.0 | 50.0 | 78.0 | 85.0 | 78.0 |
| **50%** | 2.0 | 165.0 | 53.0 | 85.0 | 88.0 | 82.0 |
| **75%** | 2.0 | 168.0 | 55.0 | 88.0 | 90.0 | 88.0 |
| **max** | 3.0 | 170.0 | 58.0 | 92.0 | 92.0 | 95.0 |

#### 각 항목 자세히 알아보기

| 항목 | 한국어 | 의미 |
|------|--------|------|
| **count** | 개수 | 비어있지 않은 데이터의 수 |
| **mean** | 평균 | 모든 값을 더해서 개수로 나눈 값 |
| **std** | 표준편차 | 값들이 평균에서 얼마나 떨어져 있는지 |
| **min** | 최솟값 | 가장 작은 값 |
| **25%** | 1사분위수 | 작은 순서로 25% 위치의 값 |
| **50%** | 중앙값 | 정확히 가운데 있는 값 |
| **75%** | 3사분위수 | 작은 순서로 75% 위치의 값 |
| **max** | 최댓값 | 가장 큰 값 |

### 표준편차(std)가 뭐예요? 🤔

학생이 5명 있는데 키가 다음과 같다고 해봐요.

- **A반**: 160, 161, 162, 163, 164 → 키가 비슷비슷! → **표준편차 작음**
- **B반**: 145, 155, 162, 175, 185 → 키 차이가 큼! → **표준편차 큼**

> 💬 **쉽게 설명하면**
> 표준편차는 "평균에서 얼마나 떨어져 있는가?"를 나타내요. 
> - 표준편차가 **작으면** → 데이터가 **고만고만**하다 (몰려있음)
> - 표준편차가 **크면** → 데이터가 **들쭉날쭉**하다 (퍼져있음)

### 특정 열만 통계 보기

```python
# 수학 점수만 통계 보기
df['수학'].describe()

# 평균만 보기
df['수학'].mean()

# 최댓값만 보기
df['수학'].max()

# 최솟값만 보기
df['수학'].min()
```

### 통계 함수 모음

| 함수 | 역할 |
|------|------|
| `mean()` | 평균 |
| `median()` | 중앙값 |
| `mode()` | 최빈값 (가장 많이 나온 값) |
| `sum()` | 합계 |
| `max()` | 최댓값 |
| `min()` | 최솟값 |
| `std()` | 표준편차 |
| `var()` | 분산 |
| `count()` | 개수 |

```python
# 활용 예시
print(f"수학 평균: {df['수학'].mean():.1f}점")
print(f"수학 최고점: {df['수학'].max()}점")
print(f"수학 총합: {df['수학'].sum()}점")
```

## 4. 범주형 데이터 분석하기 🏷️

### 범주형 데이터(Categorical Data)란?

**범주형 데이터** = 종류로 나눌 수 있는 데이터예요.

| 범주형 (글자/구분) | 수치형 (숫자) |
|-------------------|---------------|
| 성별 (남/여) | 키 (162cm) |
| MBTI (16가지) | 점수 (85점) |
| 혈액형 (A/B/O/AB) | 몸무게 (50kg) |
| 학년 (1/2/3) | 시험 횟수 |
| 좋아하는 과목 | 공부 시간 |

> 🤔 **헷갈려요!**
> 학년이나 반은 숫자인데 왜 범주형이에요?
> 
> "1반 + 2반 = 3반"이 말이 되나요? 안 되죠. 
> 숫자라도 **계산이 의미 없으면 범주형**이에요!

### `value_counts()`: 빈도수 세기

```python
# 각 반에 학생이 몇 명씩 있는지
df['반'].value_counts()
```

#### 실행 결과
```
반
1    2
2    2
3    1
Name: count, dtype: int64
```

→ 1반 2명, 2반 2명, 3반 1명이라는 뜻!

### `unique()`: 고유한 값 종류 보기

```python
# 우리 반에 있는 성별 종류
df['성별'].unique()
```

**결과**: `array(['여'], dtype=object)` → 여학생만 있네요!

```python
# 반의 종류
df['반'].unique()
```

**결과**: `array([1, 2, 3])` → 1반, 2반, 3반이 있어요.

### `nunique()`: 고유한 값의 개수

```python
# 반이 총 몇 개?
df['반'].nunique()  # 결과: 3
```

### 활용 예시: 인기 MBTI 순위

```python
# MBTI별 학생 수 (많은 순)
df_mbti['MBTI'].value_counts()

# 상위 3개만
df_mbti['MBTI'].value_counts().head(3)

# 비율로 보기 (전체 중 %)
df_mbti['MBTI'].value_counts(normalize=True) * 100
```

## 5. 종합 실습: 우리 반 분석 보고서 만들기 📝

학생 데이터로 미니 보고서를 만들어 봅시다!

```python
import pandas as pd

# 데이터 불러오기
df = pd.read_csv('students.csv')

# ① 우리 반 학생 수
print(f"전체 학생 수: {df.shape[0]}명")

# ② 키 큰 순 TOP 3
print("\n📏 키 큰 순 TOP 3")
print(df.sort_values(by='키', ascending=False).head(3)[['이름', '키']])

# ③ 수학 점수 통계
print("\n📐 수학 점수 통계")
print(f"평균: {df['수학'].mean():.1f}점")
print(f"최고: {df['수학'].max()}점")
print(f"최저: {df['수학'].min()}점")

# ④ 반별 인원
print("\n👥 반별 인원")
print(df['반'].value_counts())
```

## 6. 자주 하는 실수 ⚠️

### 실수 1: `by=` 빠뜨리기

```python
df.sort_values('수학')           # ⭕ 작동은 하지만
df.sort_values(by='수학')        # ⭕ 더 명확하고 권장!
```

### 실수 2: 정렬 후 원본이 바뀌었다고 생각하기

```python
df.sort_values(by='수학')   # 결과만 보여줌, 원본은 그대로!
df = df.sort_values(by='수학')  # 이렇게 해야 변수에 저장됨!
```

> 💡 **중요한 개념**
> Pandas 함수는 대부분 **원본을 바꾸지 않아요**. 결과를 새로 변수에 저장하거나 화면에 보여줄 뿐이에요. 원본을 바꾸려면 `inplace=True`를 쓰거나 변수에 다시 저장해야 해요.

### 실수 3: `describe()`는 숫자 열만!

```python
df.describe()                    # 숫자 열만 자동으로 통계 보여줌
df.describe(include='object')    # 문자 열의 통계 보고 싶을 때
df.describe(include='all')       # 모든 열 통계 보고 싶을 때
```
