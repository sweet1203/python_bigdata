# 6차시: 전처리 — 결측치

> 🎯 **이번 시간 학습 목표**
> - `isna()` / `notna()`로 결측 위치를 확인한다.
> - `isna().sum()`으로 **열별 결측 개수**를 센다.
> - `fillna`, `dropna`로 분석 가능한 형태로 정제한다.

**데이터**: **seaborn `penguins`** — 원래 일부 행에 결측이 들어 있습니다.

---

## 실습 전 공통 준비 코드

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** **`+ 코드`로 셀을 추가**한 뒤, **단계별 블록**을 순서대로 복사해 실행하세요.

**1단계** — 라이브러리

```python
import pandas as pd
import seaborn as sns
```

**2단계** — 데이터 불러오기

```python
df = sns.load_dataset("penguins")
```

**3단계** — 열별 결측 개수

```python
df.isna().sum()
```

---

## 1. 결측 개수 확인

```python
df.isna().sum()
```

---

## 2. 숫자 열: 중앙값·평균으로 채우기

```python
df["bill_length_mm"] = df["bill_length_mm"].fillna(df["bill_length_mm"].median())
```

---

## 3. 범주 열: 특정 문자열로 채우기

```python
df["sex"] = df["sex"].fillna("unknown")
```

---

## 4. 행 삭제

**1단계** — 아직 NaN이 있는 행은 모두 제거한 새 표

```python
df_clean = df.dropna()
```

**2단계** — `species` 열에 NaN인 행만 제거 (다른 열 결측은 남을 수 있음)

```python
df_clean = df.dropna(subset=["species"])
```

---

## 5. 정리

- 결측 탐지: `isna()`, 집계: `isna().sum()`
- 채우기: `fillna`, 필요 시 `dropna`
