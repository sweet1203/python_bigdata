# 6차시: 완성도 높은 데이터를 위한 전처리 (결측치)

> 🎯 **이번 시간 학습 목표**
> - **결측치(NaN)**가 무엇이고 왜 문제가 되는지 이해한다.
> - `isna()`, `isnull()`로 결측치를 **확인**할 수 있다.
> - `dropna()`, `fillna()`로 결측치를 **처리**할 수 있다.
> - 상황에 맞는 결측치 처리 방법을 선택할 수 있다.

---

## 1. 결측치(NaN)란? 🕳️

### 결측치 = 빠진 값

여러분이 친구 5명에게 키를 물어봤어요. 그런데 한 친구가 "나 키 안 가르쳐줄래!"라고 했다면? 그 자리는 **비어있게** 되겠죠?

이렇게 데이터에서 **값이 비어있는 것**을 **결측치**라고 해요.

| 이름 | 키 | 몸무게 | 시력 |
|------|-----|--------|------|
| 민지 | 162 | 50 | 1.0 |
| 서연 | 168 | NaN | 0.8 |
| 지우 | NaN | 48 | 1.2 |
| 하은 | 165 | 53 | NaN |
| 채원 | 170 | 58 | 0.9 |

> 💡 **NaN이 뭐예요?**
> **NaN** = "Not a Number"의 줄임말로, **'숫자가 아니다'** 또는 **'값이 없다'**는 뜻이에요. Pandas에서 빈 데이터는 `NaN`으로 표시돼요.

### 결측치가 생기는 이유

- 📝 **응답 거부**: 설문조사에서 답을 안 함
- 🔧 **장비 오류**: 센서 고장
- ⏰ **시간 부족**: 일부만 입력됨
- 🚫 **해당 없음**: 미혼자에게 자녀 수를 물음
- 💾 **시스템 오류**: 저장 중 손실

---

## 2. 결측치를 그대로 두면 어떻게 될까요? ⚠️

### 결측치의 무서운 영향

```python
# 평균 계산 예시
점수 = [85, 90, NaN, 70]
평균 = (85 + 90 + NaN + 70) / 4
# 결과: NaN!
```

> ⚠️ **충격적인 사실!**
> 데이터 100개 중 **단 1개라도 NaN**이 있으면, 평균을 계산할 때 결과가 NaN이 될 수 있어요!

### 결측치 처리의 중요성

- ❌ 통계 계산이 **오류** 발생
- ❌ **시각화**가 깨짐
- ❌ **머신러닝** 모델 학습 불가능
- ❌ **잘못된 결론** 도출

> 💬 **선생님 한마디**
> 데이터 과학자가 일하는 시간의 **80%는 데이터 전처리**에 쓴다고 해요! 그만큼 중요한 작업이에요.

## 3. 결측치 확인하기 🔍

### `isna()` / `isnull()`: 결측치 여부 확인

두 함수는 완전히 똑같이 작동해요. 이름만 다를 뿐!

```python
import pandas as pd
import numpy as np

# 결측치가 있는 데이터 만들기
data = {
    '이름': ['민지', '서연', '지우', '하은', '채원'],
    '키': [162, 168, np.nan, 165, 170],
    '몸무게': [50, np.nan, 48, 53, 58],
    '시력': [1.0, 0.8, 1.2, np.nan, 0.9]
}
df = pd.DataFrame(data)
df
```

#### 실습 1: 어디에 결측치가 있는지 확인

```python
# 각 칸이 결측치인지 True/False로 보여줌
df.isna()
```

#### 결과
| 이름 | 키 | 몸무게 | 시력 |
|------|------|--------|------|
| False | False | False | False |
| False | False | True | False |
| False | True | False | False |
| False | False | False | True |
| False | False | False | False |

> 🌟 **True가 결측치(NaN)예요!**

#### 실습 2: 열별 결측치 개수 세기

```python
df.isna().sum()
```

#### 결과
```
이름      0
키       1
몸무게    1
시력      1
dtype: int64
```

> 📊 **해석**: 키, 몸무게, 시력에 각각 1개씩 결측치가 있어요!

#### 실습 3: 전체 결측치 개수

```python
df.isna().sum().sum()
# 결과: 3
```

> 💡 `.sum()`을 두 번 쓰면 모든 결측치 개수를 더할 수 있어요!

#### 실습 4: 결측치 비율 계산

```python
# 결측치 비율 (%)
(df.isna().sum() / len(df)) * 100
```

#### 결과
```
이름     0.0
키      20.0   ← 5명 중 1명이라 20%
몸무게   20.0
시력     20.0
```

### `notna()`: 결측치가 아닌 것 확인

```python
# 결측치가 아닌 것은 True
df.notna()

# 키 데이터가 있는 학생들만
df[df['키'].notna()]
```

## 4. 결측치 처리 방법 🛠️

결측치를 처리하는 방법은 크게 **두 가지**예요:

### 방법 1: 삭제하기 (`dropna`) 🗑️
- 결측치가 있는 행이나 열을 **그냥 없애기**
- 데이터가 충분히 많고, 결측치가 적을 때 유용

### 방법 2: 채우기 (`fillna`) 🧱
- 결측치를 **다른 값으로 대체**
- 데이터를 보존하고 싶을 때 유용

> 🎯 **언제 어떤 방법을 쓸까?**
> - 데이터 100명 중 결측치 5명 → **삭제** (큰 영향 없음)
> - 데이터 100명 중 결측치 50명 → **채우기** (삭제하면 데이터가 너무 줄어듦)

---

## 5. 결측치 삭제하기: `dropna()` 🗑️

### 기본 사용법

```python
df.dropna()
```

이 함수는 **결측치가 하나라도 있는 행을 모두 삭제**해요.

#### 실습 5: 결측치 행 삭제 전후 비교

**삭제 전 (5명)**:
| 이름 | 키 | 몸무게 | 시력 |
|------|-----|--------|------|
| 민지 | 162 | 50 | 1.0 |
| 서연 | 168 | NaN | 0.8 |
| 지우 | NaN | 48 | 1.2 |
| 하은 | 165 | 53 | NaN |
| 채원 | 170 | 58 | 0.9 |

```python
df_clean = df.dropna()
df_clean
```

**삭제 후 (2명만 남음!)**:
| 이름 | 키 | 몸무게 | 시력 |
|------|-----|--------|------|
| 민지 | 162 | 50 | 1.0 |
| 채원 | 170 | 58 | 0.9 |

> ⚠️ **주의!**
> 결측치가 한 개만 있어도 그 행 전체가 삭제돼요. 데이터가 너무 많이 줄어들 수 있어요!

### `dropna`의 옵션들

```python
# 1. 기본: 결측치가 하나라도 있는 행 삭제
df.dropna()

# 2. 모든 값이 결측치인 행만 삭제
df.dropna(how='all')

# 3. 특정 열에 결측치가 있는 행만 삭제
df.dropna(subset=['키'])  # 키가 NaN인 행만 삭제

# 4. 결측치가 있는 '열'을 삭제
df.dropna(axis=1)
```

| 옵션 | 의미 |
|------|------|
| `how='any'` (기본) | 결측치가 하나라도 있으면 삭제 |
| `how='all'` | 모든 값이 결측치일 때만 삭제 |
| `subset=['열']` | 특정 열의 결측치만 봄 |
| `axis=0` (기본) | 행 삭제 |
| `axis=1` | 열 삭제 |

## 6. 결측치 채우기: `fillna()` 🧱

결측치를 다른 값으로 채우면 데이터를 보존할 수 있어요.

### 방법 1: 특정 값으로 채우기

```python
# 모든 결측치를 0으로 채우기
df.fillna(0)

# 결측치를 '없음'이라는 글자로
df.fillna('없음')
```

### 방법 2: 평균값으로 채우기 (가장 많이 사용!)

```python
# 키의 결측치를 키의 평균값으로 채우기
df['키'].fillna(df['키'].mean())
```

#### 실습 6: 평균으로 채우기

```python
# 키 평균 계산
키평균 = df['키'].mean()
print(f"키 평균: {키평균}")  # 결과: 166.25

# 결측치를 평균으로 채우기
df['키'] = df['키'].fillna(키평균)
df
```

### 방법 3: 중앙값으로 채우기

```python
# 키의 결측치를 중앙값으로
df['키'].fillna(df['키'].median())
```

> 🤔 **평균 vs 중앙값?**
> 데이터에 **이상치(outlier)** 가 있을 때는 **중앙값**이 더 안전해요!
> 
> 예: 학생들 용돈 [3만, 5만, 4만, 6만, 1000만]
> - 평균: 약 204만 원 (1000만 원 한 명 때문에 왜곡!)
> - 중앙값: 5만 원 (실제와 비슷!)

### 방법 4: 최빈값으로 채우기 (범주형 데이터)

```python
# MBTI의 결측치를 가장 많이 나온 값으로
df['MBTI'].fillna(df['MBTI'].mode()[0])
```

> 💡 **`mode()[0]`?**
> `mode()`는 최빈값을 Series로 돌려줘요. 첫 번째 값을 가져오려고 `[0]`을 붙여요!

### 방법 5: 앞/뒤 값으로 채우기 (시계열 데이터)

```python
# 앞의 값으로 채우기 (forward fill)
df.fillna(method='ffill')

# 뒤의 값으로 채우기 (backward fill)
df.fillna(method='bfill')
```

> 📅 **언제 사용?**
> 날씨 데이터 같은 시계열에서 유용해요. 어제 기온이 빠졌으면 그제 기온으로 추측하는 거죠!

## 7. `inplace` 옵션 이해하기 🔄

### 원본을 바꿀까, 결과만 볼까?

```python
# 결과만 보여주고 원본은 그대로
df.fillna(0)

# 원본 데이터프레임을 직접 바꿈
df.fillna(0, inplace=True)

# 또는 결과를 다시 변수에 저장
df = df.fillna(0)
```

> 💬 **선생님 팁**
> `inplace=True`는 **되돌리기가 안 돼요**! 처음에는 결과를 새 변수에 저장하는 게 더 안전해요!

## 8. 종합 실습: 단계별 데이터 정제 🧹

```python
import pandas as pd
import numpy as np

# 1단계: 데이터 불러오기
df = pd.read_csv('students_with_missing.csv')

# 2단계: 결측치 현황 파악
print("=" * 30)
print("📊 데이터 정보")
print("=" * 30)
print(f"전체 데이터: {len(df)}행")
print(f"\n열별 결측치:")
print(df.isna().sum())

# 3단계: 처리 전략 세우기
print("\n📋 처리 전략")
print("- 키, 몸무게: 평균값으로 채우기")
print("- 시력: 중앙값으로 채우기")
print("- 이름이 없는 행: 삭제")

# 4단계: 결측치 처리
df = df.dropna(subset=['이름'])  # 이름 없는 행은 분석 불가
df['키'] = df['키'].fillna(df['키'].mean())
df['몸무게'] = df['몸무게'].fillna(df['몸무게'].mean())
df['시력'] = df['시력'].fillna(df['시력'].median())

# 5단계: 결과 확인
print("\n" + "=" * 30)
print("✨ 처리 후")
print("=" * 30)
print(f"데이터: {len(df)}행")
print(f"남은 결측치: {df.isna().sum().sum()}개")
```

## 10. 자주 하는 실수 ⚠️

### 실수 1: 결측치인지 모르고 분석 시작

```python
# ❌ 결측치 확인 없이 바로 분석
df['키'].mean()   # NaN이 결과로 나올 수 있음!

# ⭕ 먼저 확인하고 처리한 후 분석
df.isna().sum()
df['키'] = df['키'].fillna(df['키'].mean())
df['키'].mean()
```

### 실수 2: `inplace=True` 잘못 사용

```python
# ❌ 결과를 변수에 저장하고 inplace도 사용 (이상한 결과)
df = df.fillna(0, inplace=True)   # df가 None이 됨!

# ⭕ 둘 중 하나만!
df.fillna(0, inplace=True)        # 원본 변경
# 또는
df = df.fillna(0)                 # 새로 저장
```

### 실수 3: 모든 열에 같은 처리 적용

```python
# ❌ 이름까지 0으로 채워짐
df.fillna(0)

# ⭕ 열별로 다르게 처리
df['키'] = df['키'].fillna(df['키'].mean())
df['이름'] = df['이름'].fillna('이름 미상')
```

### 실수 4: 빈 문자열을 결측치로 인식 못 함

```python
# 빈 문자열 ''은 NaN이 아니라서 isna()로 안 잡힘!
# 미리 NaN으로 바꿔주기
df = df.replace('', np.nan)
df.isna().sum()
```

## 11. 정리하기 ✏️

### 핵심 함수 요약

| 함수 | 역할 |
|------|------|
| `isna()` / `isnull()` | 결측치인지 True/False |
| `notna()` | 결측치가 아닌지 True/False |
| `isna().sum()` | 열별 결측치 개수 |
| `dropna()` | 결측치 행 삭제 |
| `fillna(값)` | 결측치를 값으로 채움 |
| `fillna(df.mean())` | 평균으로 채움 |
| `fillna(df.median())` | 중앙값으로 채움 |
| `fillna(df.mode()[0])` | 최빈값으로 채움 |
