# 6차시: 전처리 — 결측치

> 🎯 **이번 시간 학습 목표**
> - `isna()` / `notna()`로 결측 위치를 확인한다.
> - `isna().sum()`으로 **열별 결측 개수**를 센다.
> - `fillna`, `dropna`로 분석 가능한 형태로 정제한다.

**데이터**: **seaborn `penguins`** — 원래 일부 행에 결측이 들어 있습니다.

---

## 실습 전 공통 준비 코드

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

**준비** — 라이브러리 + 데이터

```python
import pandas as pd
import seaborn as sns

df = sns.load_dataset("penguins")
```

**출력** — 열별 결측 개수

```python
df.isna().sum()
```

---

## 1. 결측 개수 확인

```python
df.isna().sum()
```

---

## 2. 숫자 열: 중앙값·평균으로 채우기

```python
df["bill_length_mm"] = df["bill_length_mm"].fillna(df["bill_length_mm"].median())
```

---

## 3. 범주 열: 특정 문자열로 채우기

```python
df["sex"] = df["sex"].fillna("unknown")
```

---

## 4. 행 삭제

**예시 1** — NaN이 하나라도 있는 행은 모두 제거

```python
df_clean = df.dropna()
```

**예시 2** — `species` 열에만 NaN인 행만 제거 (다른 열 결측은 남을 수 있음)

```python
df_clean = df.dropna(subset=["species"])
```

---

## 5. 정리

- 결측 탐지: `isna()`, 집계: `isna().sum()`
- 채우기: `fillna`, 필요 시 `dropna`

### 💪 도전 과제

펭귄 데이터의 결측치를 직접 처리해 보세요!

```python
# 준비 코드 (이미 실행했다면 생략)
import pandas as pd
import seaborn as sns
df = sns.load_dataset("penguins")

# 문제 1. 열별 결측치 개수를 확인하세요
df.isna().sum()

# 문제 2. 'body_mass_g'의 결측치를 평균으로 채우기
#         (수업에서 중앙값을 써봤으니, 이번엔 평균으로!)
df["body_mass_g"] = df["body_mass_g"].fillna(df["body_mass_g"].mean())

# 문제 3. 'sex' 열에만 결측이 있는 행을 삭제하기
#         (힌트: dropna의 subset 옵션!)
df = df.dropna(subset=["sex"])

# 문제 4. 처리 후 결측치가 남아 있는지 다시 확인
df.isna().sum()
```

> 💡 **왜 subset?** `dropna()`는 기본적으로 NaN이 하나라도 있는 행 전체를 지워요. `subset=["sex"]`처럼 특정 열만 지정하면 그 열만 보고 판단해요!
