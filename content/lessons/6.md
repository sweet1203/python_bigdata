# 6차시: 전처리 — 결측치

> 🎯 **이번 시간 학습 목표**
> - `isna()` / `notna()`로 결측 위치를 확인한다.
> - `isna().sum()`으로 **열별 결측 개수**를 센다.
> - `fillna`, `dropna`로 분석 가능한 형태로 정제한다.

**데이터**: **seaborn `penguins`** — 원래 일부 행에 결측이 들어 있습니다.

---

## 실습 전 공통 준비 코드

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** **`import`와 `df = ...`** 는 **한 블록**입니다. **열별 결측 개수**는 표로 보이므로 **다음 셀**에 두었습니다.

**준비** — 라이브러리 + 데이터

```python
import pandas as pd
import seaborn as sns

df = sns.load_dataset("penguins")
```

**출력** — 열별 결측 개수

```python
df.isna().sum()
```

---

## 1. 결측 개수 확인

```python
df.isna().sum()
```

---

## 2. 숫자 열: 중앙값·평균으로 채우기

```python
df["bill_length_mm"] = df["bill_length_mm"].fillna(df["bill_length_mm"].median())
```

---

## 3. 범주 열: 특정 문자열로 채우기

```python
df["sex"] = df["sex"].fillna("unknown")
```

---

## 4. 행 삭제

**예시 1** — NaN이 하나라도 있는 행은 모두 제거

```python
df_clean = df.dropna()
```

**예시 2** — `species` 열에만 NaN인 행만 제거 (다른 열 결측은 남을 수 있음)

```python
df_clean = df.dropna(subset=["species"])
```

---

## 5. 정리

- 결측 탐지: `isna()`, 집계: `isna().sum()`
- 채우기: `fillna`, 필요 시 `dropna`
