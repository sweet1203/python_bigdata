## 1. 우리는 매일 데이터를 만들고 있어요 📱

여러분이 오늘 아침부터 지금까지 한 일을 떠올려 볼까요?

- 알람을 끄고 인스타그램을 5분 동안 봤어요. → **이용 시간 데이터**
- 등굣길에 편의점에서 삼각김밥을 샀어요. → **결제 데이터**
- 유튜브에서 좋아하는 가수의 뮤직비디오를 봤어요. → **시청 기록 데이터**
- 친구에게 카톡으로 "오늘 뭐 입었어?"라고 보냈어요. → **메시지 데이터**

이렇게 우리의 모든 행동은 **숫자나 글자로 기록**되고, 이것을 **데이터(Data)** 라고 합니다.

### 데이터, 정보, 지혜의 차이

데이터를 그냥 모아두기만 하면 의미가 없어요. 마치 정리되지 않은 책상 위의 종이 더미와 같죠. 이 데이터를 잘 정리하고 분석해야 우리에게 도움이 되는 **'정보'**, 더 나아가 **'지혜'**가 됩니다.

| 단계 | 예시 | 설명 |
|------|------|------|
| 📊 **데이터(Data)** | "구미진 / 162cm / 50kg / 수학 85점" | 수집된 원래의 기록 |
| 💡 **정보(Information)** | "우리 반 평균 키는 161cm" | 데이터를 정리해서 알게 된 사실 |
| 🌟 **지혜(Wisdom)** | "키가 큰 학생일수록 농구를 좋아한다" | 정보를 바탕으로 얻은 통찰력 |

> 💬 **선생님 한마디**
> 데이터 분석은 결국 "**숨겨진 이야기**를 찾아내는 일"이에요. 마치 탐정이 단서를 모아 사건을 해결하듯이요!

## 2. 왜 파이썬과 Pandas일까요? 🐼

### 파이썬(Python)이란?

파이썬은 **사람의 말과 가장 비슷한** 프로그래밍 언어입니다. 영어를 조금만 알아도 코드가 무슨 뜻인지 짐작할 수 있을 정도예요.

```python
# 파이썬 예시 - 영어 문장처럼 읽혀요!
if score >= 90:
    print("축하합니다!")
```

위 코드는 "만약 점수가 90 이상이면, '축하합니다'를 출력하라"는 뜻이에요. 어때요? 영어 문장을 읽는 느낌이죠?

### 그런데 파이썬만으로는 부족해요

파이썬 기본 기능만으로 우리 학교 전교생 500명의 성적표를 다룬다고 생각해 봐요. 학생마다 이름, 반, 번호, 국·영·수 점수를 따로따로 관리해야 한다면 너무 복잡하겠죠?

### 그래서 등장한 Pandas! 🐼

**Pandas(판다스)**는 파이썬에서 **표 형태의 데이터를 쉽게 다룰 수 있게 해주는 도구**예요.

> 🌟 **재미있는 사실!**
> Pandas의 이름은 귀여운 동물 판다에서 따온 게 아니라, **"Panel Data"** 라는 통계 용어를 줄인 말이에요. 그런데 마침 글자가 판다와 같아서 로고도 판다 모양이 됐답니다!

### Pandas로 할 수 있는 일

| 기능 | 비유하자면... |
|------|--------------|
| 📂 데이터 불러오기 | 책장에서 책 꺼내기 |
| 🔍 데이터 찾기 | 책에서 원하는 페이지 펼치기 |
| ✏️ 데이터 수정하기 | 책에 메모 추가하기 |
| 📊 데이터 요약하기 | 책 줄거리 정리하기 |
| 🎨 데이터 시각화 | 책 내용으로 그림 그리기 |

## 3. 오렌지3 vs 파이썬 코랩 🍊 vs 🐍

지금까지 여러분은 **오렌지3**에서 마우스로 위젯을 끌어다 놓으며 데이터를 분석했어요. 이제는 한 단계 더 나아가서, **코드를 직접 입력**해 볼 거예요.

### 두 도구의 차이점

| 비교 항목 | 🍊 오렌지3 | 🐍 파이썬 코랩 |
|----------|-----------|---------------|
| 사용 방법 | 위젯을 마우스로 드래그 | 코드를 키보드로 입력 |
| 난이도 | 쉬움 (직관적) | 처음엔 어렵지만 익숙해지면 강력함 |
| 자유도 | 정해진 위젯만 사용 가능 | 원하는 분석을 자유롭게! |
| 결과 공유 | 화면 캡처해서 공유 | 링크 하나로 공유 가능 |

> 💡 **걱정 마세요!**
> 오렌지3에서 했던 모든 분석을 파이썬에서도 똑같이 할 수 있어요. 다만 **"손가락(드래그)" 대신 "글자(코드)"로** 명령을 내리는 거예요.

### 코랩(Colab)이란?

**구글 코랩(Google Colab)**은 구글에서 무료로 제공하는 파이썬 실행 환경이에요.

- ✅ 설치 필요 없음 (인터넷 브라우저만 있으면 OK)
- ✅ 구글 계정만 있으면 누구나 사용 가능
- ✅ 만든 파일은 구글 드라이브에 자동 저장
- ✅ 친구와 링크로 공유 가능

**접속 방법**: [https://colab.research.google.com](https://colab.research.google.com) 에 접속 → 구글 계정 로그인 → "새 노트" 클릭!

## 4. 첫 실습: MBTI 데이터로 친해지기 ✨

이제 직접 코드를 실행해 봅시다. 처음이라 코드가 외계어처럼 보일 수 있지만, **한 줄씩 천천히** 따라 해 보세요.

### 실습 코드

```python
# ① 판다스 라이브러리 불러오기 (도구 상자 열기!)
import pandas as pd

# ② 시각화 라이브러리 불러오기 (그림 그리는 도구!)
import matplotlib.pyplot as plt

# ③ MBTI 데이터 불러오기
df_mbti = pd.read_csv('./data/MBTI.csv')

# ④ 처음 5줄만 미리 살펴보기
df_mbti.head()
```

### 코드 한 줄씩 자세히 알아보기

#### ① `import pandas as pd`
- **뜻**: "판다스라는 도구 상자를 가져와서, 앞으로 `pd`라는 짧은 이름으로 부를게!"
- **왜 짧게?**: `pandas.read_csv(...)` 보다 `pd.read_csv(...)`가 훨씬 짧고 편하니까요.

#### ② `import matplotlib.pyplot as plt`
- **뜻**: "그래프 그리는 도구를 가져와서, `plt`라고 부를게!"
- 마찬가지로 `matplotlib.pyplot`은 너무 길어서 `plt`로 줄여 써요.

#### ③ `df_mbti = pd.read_csv('./data/MBTI.csv')`
- **뜻**: "data 폴더 안의 MBTI.csv 파일을 읽어서, `df_mbti`라는 이름의 변수에 저장해!"
- **`df`의 의미**: DataFrame(데이터프레임)의 줄임말. 표 형태의 데이터를 담는 그릇이에요.

#### ④ `df_mbti.head()`
- **뜻**: "`df_mbti`의 머리(head) 부분, 즉 처음 5줄만 보여줘!"
- 데이터가 1000줄이어도 한꺼번에 다 보면 정신없으니까, 일단 앞부분만 살짝 확인하는 거예요.

## 6. 자주 하는 실수와 해결법 🛠️

### 실수 1: 파일을 못 찾는다는 오류
```
FileNotFoundError: [Errno 2] No such file or directory
```
**해결**: 파일 경로가 정확한지 확인! 코랩에서는 왼쪽 폴더 아이콘 📁 을 클릭해서 파일을 직접 업로드해야 해요.

### 실수 2: 라이브러리를 안 불러옴
```
NameError: name 'pd' is not defined
```
**해결**: 코드 맨 위에 `import pandas as pd`를 꼭 써주세요!

### 실수 3: 따옴표를 안 맞춤
```python
df = pd.read_csv('data.csv")  # ❌ 작은따옴표와 큰따옴표가 섞임
df = pd.read_csv('data.csv')  # ⭕ 정확함
```
**해결**: 따옴표는 양쪽이 같은 종류여야 해요!
