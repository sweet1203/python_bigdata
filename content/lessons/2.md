## 1. 데이터의 두 가지 모양 📦

판다스에는 데이터를 담는 두 종류의 '그릇'이 있어요. 바로 **Series(시리즈)**와 **DataFrame(데이터프레임)**입니다.

### Series: 한 줄짜리 데이터

**Series**는 한 줄(1차원)로 늘어선 데이터예요. 마치 출석부의 한 줄과 같아요.

| 인덱스 | 값 |
|--------|-----|
| 0 | 민지 |
| 1 | 서연 |
| 2 | 지우 |
| 3 | 하은 |

- **인덱스(Index)**: 데이터에 붙은 **이름표**예요. 기본적으로 0부터 시작하는 숫자가 붙어요.
- **값(Value)**: 실제 데이터 내용이에요.

### DataFrame: 여러 줄짜리 데이터 (표)

**DataFrame**은 여러 개의 Series가 모인 **표 형태(2차원)** 의 데이터예요. 우리가 흔히 보는 엑셀 표를 떠올리면 됩니다.

| 인덱스 | 이름 | 키 | 몸무게 | 수학 |
|--------|------|-----|--------|------|
| 0 | 민지 | 162 | 50 | 85 |
| 1 | 서연 | 168 | 55 | 92 |
| 2 | 지우 | 159 | 48 | 78 |
| 3 | 하은 | 165 | 53 | 88 |

> 💡 **쉽게 이해하기**
> - **Series** = 출석부의 '이름' 한 줄만 따로 떼어낸 것
> - **DataFrame** = 이름, 키, 몸무게, 점수 등 여러 정보가 모인 **전체 표**
> 
> 즉, **DataFrame은 여러 Series를 옆으로 붙여놓은 것**이에요!

### 오렌지3와 비교하면?

| 오렌지3 | 파이썬 Pandas |
|---------|---------------|
| Data Table 위젯의 한 컬럼(열) | Series |
| Data Table 위젯 전체 | DataFrame |

## 2. CSV 파일이 뭐예요? 📄

데이터 분석을 시작하려면 먼저 데이터를 가져와야 해요. 가장 많이 쓰는 형식이 **CSV 파일**입니다.

### CSV의 뜻

**CSV(Comma-Separated Values)** = "쉼표로 구분된 값"

이름,키,몸무게,수학  
민지,162,50,85  
서연,168,55,92  
지우,159,48,78

위처럼 **쉼표(,)** 로 데이터를 구분해 놓은 텍스트 파일이에요. 메모장으로도 열 수 있을 만큼 단순해서 전 세계가 사랑하는 형식이랍니다. ❤️

> 🔍 **궁금증 해결!**
> Q. 엑셀 파일(.xlsx)이랑 뭐가 달라요?
> A. 엑셀 파일은 글자 색, 셀 병합 같은 꾸미기 정보까지 들어있는 **무거운 파일**이에요. CSV는 오직 데이터만 담은 **가벼운 파일**이라 컴퓨터가 처리하기 빠릅니다.

## 3. 실습: 우리 반 데이터 불러오기 🎒

이번 실습에서 사용할 가상의 데이터예요. (`students.csv`)

| 이름 | 반 | 성별 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|------|------|------|-----|--------|------|------|------|
| 민지 | 1 | 여 | 162 | 50 | 85 | 90 | 78 |
| 서연 | 1 | 여 | 168 | 55 | 92 | 88 | 95 |
| 지우 | 2 | 여 | 159 | 48 | 78 | 82 | 70 |
| 하은 | 2 | 여 | 165 | 53 | 88 | 85 | 82 |
| 채원 | 3 | 여 | 170 | 58 | 75 | 92 | 88 |

### 실습 1: 데이터 불러오기와 미리보기

```python
# 판다스 도구 가져오기
import pandas as pd

# CSV 파일 읽어서 df 변수에 저장
df = pd.read_csv('students.csv')

# 처음 5줄 미리보기
df.head()
```

#### `head()` 함수 자세히 알아보기

`head()`는 데이터의 **머리(앞부분)**를 보여주는 함수예요.

```python
df.head()      # 기본값: 앞에서 5줄
df.head(3)     # 앞에서 3줄만
df.head(10)    # 앞에서 10줄
```

> 📌 **왜 처음 5줄만?**
> 데이터가 수천, 수만 줄일 수도 있는데 한꺼번에 다 보면 화면이 꽉 차고 정신없겠죠? 일단 5줄만 보고 "아, 이런 모양의 데이터구나!" 하고 파악하는 거예요.

### 실습 2: 데이터의 마지막 부분 확인하기

```python
df.tail()      # 마지막 5줄
df.tail(3)     # 마지막 3줄
```

`tail()`은 **꼬리(끝부분)**를 보여주는 함수예요. 데이터가 끝까지 잘 들어있는지 확인할 때 자주 써요.

> 🐠 **외우기 팁**
> 동물의 머리(head)와 꼬리(tail)를 떠올리면 외우기 쉬워요!

## 4. 데이터의 전체 구조 파악하기 🔍

데이터를 받으면 가장 먼저 해야 할 일은 **"이 데이터가 어떻게 생겼지?"** 하고 파악하는 거예요.

### 실습 3: `info()` 함수로 데이터 정보 확인

```python
df.info()
```

#### 실행 결과 예시

```
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 5 entries, 0 to 4
Data columns (total 8 columns):
 #   Column   Non-Null Count  Dtype  
---  ------   --------------  -----  
 0   이름      5 non-null      object 
 1   반       5 non-null      int64  
 2   성별      5 non-null      object 
 3   키       5 non-null      int64  
 4   몸무게    5 non-null      int64  
 5   국어      5 non-null      int64  
 6   영어      5 non-null      int64  
 7   수학      5 non-null      int64  
dtypes: int64(6), object(2)
```

#### 결과 해석하기

| 항목 | 의미 |
|------|------|
| **RangeIndex: 5 entries** | 행이 총 5개 있다 |
| **total 8 columns** | 열이 총 8개 있다 |
| **Non-Null Count** | 비어있지 않은 데이터의 개수 |
| **Dtype** | 데이터 타입 (자료형) |

### 데이터 타입(Dtype) 종류

| Dtype | 의미 | 예시 |
|-------|------|------|
| `int64` | 정수 (소수점 없는 숫자) | 162, 50, 85 |
| `float64` | 실수 (소수점 있는 숫자) | 162.5, 50.3 |
| `object` | 문자열 (글자) | "민지", "여" |
| `bool` | 참/거짓 | True, False |
| `datetime64` | 날짜/시간 | 2024-03-15 |

> 💬 **선생님 팁**
> `object` 타입이 보이면 "아, 이건 글자 데이터구나!"라고 생각하면 돼요. 숫자 계산은 안 되니까요.

### 실습 4: `shape`로 크기 확인하기

```python
df.shape
```

**결과 예시**: `(5, 8)` → "5행 8열"이라는 뜻이에요.

```python
# 행 개수만 알고 싶을 때
df.shape[0]   # 5

# 열 개수만 알고 싶을 때  
df.shape[1]   # 8
```

### 실습 5: 열(Column) 이름 확인하기

```python
df.columns
```

**결과 예시**: `Index(['이름', '반', '성별', '키', '몸무게', '국어', '영어', '수학'], dtype='object')`

## 5. 특정 열만 골라보기 🎯

DataFrame에서 한 열만 따로 보고 싶을 때는 어떻게 할까요?

```python
# 수학 점수 열만 보기
df['수학']

# 결과 (이게 바로 Series예요!)
# 0    78
# 1    95
# 2    70
# 3    82
# 4    88
# Name: 수학, dtype: int64
```

> 🌟 **포인트!**
> DataFrame에서 한 열을 뽑으면 **Series**가 됩니다. 1차원이 됐죠?

### 여러 열을 동시에 보려면?

```python
# 이름, 수학 두 개의 열만 보기 (대괄호가 두 번!)
df[['이름', '수학']]
```

> ⚠️ **주의**
> 한 열만 볼 때는 `df['수학']` (대괄호 1개), 여러 열을 볼 때는 `df[['이름', '수학']]` (대괄호 2개)예요. 헷갈리지 않게 조심!

## 6. 한눈에 보는 정리 📋

### 자주 쓰는 함수 모음

| 함수 | 역할 |
|------|------|
| `pd.read_csv('파일명')` | CSV 파일 불러오기 |
| `df.head(n)` | 처음 n줄 보기 (기본 5줄) |
| `df.tail(n)` | 마지막 n줄 보기 |
| `df.info()` | 데이터 전체 정보 요약 |
| `df.shape` | (행 개수, 열 개수) |
| `df.columns` | 열 이름 목록 |
| `df['열이름']` | 특정 열 1개 가져오기 |
| `df[['열1', '열2']]` | 여러 열 가져오기 |

## 7. 자주 하는 실수 ⚠️

### 실수 1: 괄호 vs 대괄호 헷갈림
```python
# df.head[]      # ❌ 함수는 둥근 괄호!
df.head()      # ⭕ 정답

# df('이름')     # ❌ 열 선택은 대괄호!
df['이름']     # ⭕ 정답
```

### 실수 2: 열 이름 오타
```python
# df['수학점수']   # ❌ 실제 열 이름은 '수학'인데 오타!
df['수학']      # ⭕ 정확한 이름으로

# 열 이름이 헷갈리면 항상 columns로 확인하세요!
df.columns
```

### 실수 3: 한글 열 이름 사용 시 따옴표 누락
```python
# df[수학]        # ❌ 따옴표 없음 → 변수로 인식
df['수학']      # ⭕ 따옴표로 감싸기
```
