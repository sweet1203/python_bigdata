> 🎯 **이번 시간 학습 목표**
> - **Series**와 **DataFrame**의 차이를 이해한다.
> - `sns.load_dataset`으로 표 데이터를 불러올 수 있다. (1차시와 동일 **펭귄** 데이터)
> - `head()`, `tail()`, `info()`, `shape`, `columns`로 기본 정보를 파악할 수 있다.

## 실습 전 공통 준비 코드 (복사 실행용)

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** 한 셀을 실행(▶)하면 그 셀 안의 코드는 **위에서 아래로 모두** 실행됩니다. 아래 블록은 **단계별**로 나누어 두었으니, **`+ 코드`로 셀을 추가**한 뒤 블록마다 **복사 → 붙여넣기 → 실행** 순서로 따라 가면 됩니다.

**1단계** — 라이브러리

```python
import pandas as pd
import seaborn as sns
```

**2단계** — 데이터 불러오기

```python
df = sns.load_dataset("penguins")
```

**3단계** — 행·열 개수 확인

```python
df.shape
```

**4단계** — 앞부분 미리 보기

```python
df.head()
```

---

## 1. 데이터의 두 가지 모양 📦

### Series: 한 열(1차원)

한 열만 떼면 **Series**입니다. 인덱스(0,1,2…)와 값의 쌍이에요.

### DataFrame: 표(2차원)

여러 열이 모인 것이 **DataFrame**입니다. 엑셀 시트를 떠올리면 됩니다.

> 💡 **관계**
> `df['bill_length_mm']` → 한 열만 보면 **Series**  
> `df[['species', 'bill_length_mm']]` → **DataFrame** (열이 2개 이상)

---

## 2. 실습: 펭귄 데이터 살펴보기 🐧

### 실습 1: 불러오기와 `head()`

위에서 **공통 준비 코드**로 이미 `df`를 만들었다면, **같은 노트북**에서는 import와 `load_dataset`을 반복하지 않고 아래만 이어 쓰면 됩니다.

```python
df.head()
```

`head()`는 앞에서 기본 **5행**을 보여 줍니다. `head(3)`처럼 개수를 바꿀 수 있어요.

### 실습 2: `tail()`

**1단계** — 뒤에서 기본 5행

```python
df.tail()
```

**2단계** — 뒤에서 3행만

```python
df.tail(3)
```

---

## 3. 전체 구조: `info()`, `shape`

**1단계** — 열 타입·개수 요약

```python
df.info()
```

**2단계** — (행 개수, 열 개수) 튜플

```python
df.shape
```

**3단계** — 행 개수만

```python
df.shape[0]
```

**4단계** — 열 개수만

```python
df.shape[1]
```

`info()`에는 각 열의 **dtype**, **비어 있지 않은 개수** 등이 나옵니다. 펭귄 데이터는 일부 열에 **결측**이 있을 수 있어요(6차시에서 다룹니다).

---

## 4. 열 이름과 열 선택

**1단계** — 열 이름 목록

```python
df.columns
```

**2단계** — 한 열만 → Series

```python
df["species"]
```

**3단계** — 두 열 이상 → DataFrame (대괄호 두 겹)

```python
df[["species", "bill_length_mm"]]
```

> ⚠️ 열 이름은 **반드시 문자열**로: `df['species']` (따옴표)

---

## 5. 자주 쓰는 함수 모음

| 함수 | 역할 |
|------|------|
| `sns.load_dataset("penguins")` | 예제 표 불러오기 |
| `df.head(n)` | 앞 n행 (기본 5) |
| `df.tail(n)` | 뒤 n행 |
| `df.info()` | 구조·타입 요약 |
| `df.shape` | (행, 열) 크기 |
| `df.columns` | 열 이름들 |
| `df['열']` / `df[['열1','열2']]` | 열 선택 |

---

## 6. 정리하기 ✏️

- **Series** = 1차원, **DataFrame** = 2차원 표
- 이번 과정 1~6차시는 같은 **펭귄** 데이터로 문법을 익힙니다.
