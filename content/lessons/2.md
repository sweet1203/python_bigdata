# 2차시: 판다스와 친해지기 (Series와 DataFrame)

> 🎯 **이번 시간 학습 목표**
> - **Series**와 **DataFrame**의 차이를 이해한다.
> - `sns.load_dataset`으로 표 데이터를 불러올 수 있다. (1차시와 동일 **펭귄** 데이터)
> - `head()`, `tail()`, `info()`, `shape`, `columns`로 기본 정보를 파악할 수 있다.

---

## 실습 전 공통 준비 코드 (복사 실행용)

> 📎 **한 파일 제출:** 이 차시 Colab 노트북 **맨 위 셀**에만 아래 블록을 두세요. 이후 실습 코드에는 **`import`를 다시 쓰지 않습니다.**

```python
import pandas as pd
import seaborn as sns

df = sns.load_dataset("penguins")
print("데이터 크기:", df.shape)
df.head()
```

---

## 1. 데이터의 두 가지 모양 📦

### Series: 한 열(1차원)

한 열만 떼면 **Series**입니다. 인덱스(0,1,2…)와 값의 쌍이에요.

### DataFrame: 표(2차원)

여러 열이 모인 것이 **DataFrame**입니다. 엑셀 시트를 떠올리면 됩니다.

> 💡 **관계**
> `df['bill_length_mm']` → 한 열만 보면 **Series**  
> `df[['species', 'bill_length_mm']]` → **DataFrame** (열이 2개 이상)

---

## 2. 실습: 펭귄 데이터 살펴보기 🐧

### 실습 1: 불러오기와 `head()`

위에서 **공통 준비 코드**로 이미 `df`를 만들었다면, **같은 노트북**에서는 import와 `load_dataset`을 반복하지 않고 아래만 이어 쓰면 됩니다.

```python
df.head()
```

`head()`는 앞에서 기본 **5행**을 보여 줍니다. `head(3)`처럼 개수를 바꿀 수 있어요.

### 실습 2: `tail()`

```python
df.tail()
df.tail(3)
```

---

## 3. 전체 구조: `info()`, `shape`

```python
df.info()
df.shape          # (행 개수, 열 개수)
df.shape[0]       # 행만
df.shape[1]       # 열만
```

`info()`에는 각 열의 **dtype**, **비어 있지 않은 개수** 등이 나옵니다. 펭귄 데이터는 일부 열에 **결측**이 있을 수 있어요(6차시에서 다룹니다).

---

## 4. 열 이름과 열 선택

```python
df.columns

# 한 열 → Series
df["species"]

# 두 열 이상 → DataFrame (대괄호 두 겹)
df[["species", "bill_length_mm"]]
```

> ⚠️ 열 이름은 **반드시 문자열**로: `df['species']` (따옴표)

---

## 5. 자주 쓰는 함수 모음

| 함수 | 역할 |
|------|------|
| `sns.load_dataset("penguins")` | 예제 표 불러오기 |
| `df.head(n)` | 앞 n행 (기본 5) |
| `df.tail(n)` | 뒤 n행 |
| `df.info()` | 구조·타입 요약 |
| `df.shape` | (행, 열) 크기 |
| `df.columns` | 열 이름들 |
| `df['열']` / `df[['열1','열2']]` | 열 선택 |

---

## 6. 정리하기 ✏️

- **Series** = 1차원, **DataFrame** = 2차원 표
- 이번 과정 1~6차시는 같은 **펭귄** 데이터로 문법을 익힙니다.
