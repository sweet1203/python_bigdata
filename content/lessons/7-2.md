## 1. 꺾은선 그래프: plt.plot()

**시간에 따른 변화**나 순서가 있는 데이터를 볼 때 사용해요.

### 실습 1: 섬별 평균 몸무게

```python
df.groupby("island")["body_mass_g"].mean().plot(kind="line", marker="o", color="darkorange")
plt.title("Mean Body Mass by Island")
plt.xlabel("island")
plt.ylabel("mean body_mass_g")
plt.grid(True, alpha=0.3)
plt.show()
```

`groupby("island")`로 섬별로 묶어 평균을 구하고, `kind="line"`으로 꺾은선을 그려요. `marker="o"`는 각 지점에 동그란 점을 찍어 값을 잘 보이게 하고, `plt.grid()`는 격자를 옅게(`alpha=0.3`) 넣어 읽기 쉽게 해줘요.

### 실습 2: 꺾은선 꾸미기 (시간 데이터 예시)

한글 폰트 없이 영문으로 레이블을 지정하여 깔끔한 그래프를 그려요.

```python
months = ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
temps = [-2, 1, 6, 13, 18, 22]

plt.plot(months, temps, color="red", marker="o", linestyle="--", linewidth=2, label="Mean Temp")
plt.title("Monthly Mean Temperature", fontsize=15)
plt.xlabel("Month")
plt.ylabel("Temperature (°C)")
plt.legend()
plt.grid(True)
plt.show()
```

선을 꾸미는 옵션이에요. `linestyle="--"`는 점선, `linewidth=2`는 선 두께, `label="Mean Temp"`는 선의 이름을 정해요. 이 `label`은 `plt.legend()`(범례)와 짝으로 쓰여서, 그래프에 어떤 선인지 표시해줘요.

## 2. 원 그래프(파이 차트): plt.pie()

**전체에서 각 항목의 비율**을 보여줄 때 사용해요.

### 실습 3: 종별 펭귄 비율

```python
counts = df["species"].value_counts()
plt.figure(figsize=(6, 6))
plt.pie(counts, labels=counts.index, autopct="%1.1f%%", startangle=90)
plt.title("Share of Penguins by Species")
plt.show()
```

`autopct='%1.1f%%'`: 각 조각에 비율(%)을 자동으로 표시해줘요!

### 실습 4: 섬별 비율 + 한 조각 강조

```python
island_counts = df["island"].value_counts()
explode = [0.1, 0, 0]

plt.figure(figsize=(6, 6))
plt.pie(island_counts, labels=island_counts.index,
        autopct="%1.1f%%", explode=explode, shadow=True, startangle=90)
plt.title("Share of Penguins by Island")
plt.show()
```

`explode=[0.1, 0, 0]`는 첫 번째 조각만 0.1만큼 바깥으로 빼내서 **강조**해요. `shadow=True`는 그림자를, `startangle=90`은 그래프가 시작되는 각도를 위쪽(90도)으로 맞춰 보기 좋게 해줘요.

## 3. 히트맵

**여러 수치 변수들 사이의 상관관계**를 한눈에 볼 때 사용해요.

- 값이 **1에 가까울수록** 강한 양의 상관
- 값이 **-1에 가까울수록** 강한 음의 상관

### 실습 5: 펭귄 수치 데이터 상관관계

```python
num_cols = ["bill_length_mm", "bill_depth_mm", "flipper_length_mm", "body_mass_g"]
corr = df[num_cols].corr()

plt.figure(figsize=(7, 5))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="RdBu_r", center=0, linewidths=0.5)
plt.title("Correlation Heatmap (penguins numeric columns)")
plt.show()
```

`df[num_cols].corr()`로 수치 열들 사이의 상관계수 표를 먼저 만들어요. `annot=True`는 각 칸에 숫자를 표시하고, `fmt=".2f"`는 소수점 둘째 자리까지, `cmap="RdBu_r"`은 색상 테마(빨강·파랑), `center=0`은 0을 색의 기준점으로 맞춰 양수·음수를 색으로 구분해줘요.

`flipper_length_mm`과 `body_mass_g`의 값이 크면 -> 지느러미가 길수록 몸무게도 많이 나간다는 경향이 강하다는 뜻!

## 4. 여러 그래프 한 번에 (서브플롯)

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# 1번: 히스토그램
axes[0, 0].hist(df["body_mass_g"], bins=12, color="skyblue", edgecolor="black")
axes[0, 0].set_title("Body Mass Distribution")

# 2번: 막대 그래프
df["species"].value_counts().sort_index().plot(ax=axes[0, 1], kind="bar", color="seagreen")
axes[0, 1].set_title("Count by Species")
axes[0, 1].tick_params(axis="x", rotation=0)

# 3번: 산점도
axes[1, 0].scatter(df["flipper_length_mm"], df["body_mass_g"], alpha=0.5)
axes[1, 0].set_title("Flipper vs Body Mass")

# 4번: 파이 차트
counts = df["species"].value_counts()
axes[1, 1].pie(counts, labels=counts.index, autopct="%1.1f%%")
axes[1, 1].set_title("Species Share")

plt.tight_layout()
plt.show()
```

`plt.subplots(2, 2)`는 그래프를 그릴 칸을 **2행 2열(총 4칸)**로 만들어요. `axes[0, 0]`은 왼쪽 위, `axes[1, 1]`은 오른쪽 아래처럼 `[행, 열]` 번호로 칸을 골라 그려요. 각 칸은 제목을 `set_title()`로 정하고, 마지막 `plt.tight_layout()`은 그래프끼리 겹치지 않게 간격을 자동으로 정리해줘요.

## 5. 그래프 저장하기

```python
plt.hist(df["body_mass_g"], bins=15, color="skyblue", edgecolor="black")
plt.title("Penguin Body Mass")
plt.savefig("penguin_mass.png", dpi=300)
plt.show()
```

`plt.savefig("이름.png")`로 그래프를 이미지 파일로 저장해요. `dpi=300`은 해상도(높을수록 또렷)예요. ⚠️ **저장은 반드시 `plt.show()` 앞에** 해야 해요. `show()` 뒤에 쓰면 빈 이미지가 저장될 수 있어요.
