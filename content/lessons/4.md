# 4차시: 원하는 데이터만 쏙쏙! 인덱싱과 슬라이싱

> 🎯 이번 시간 학습 목표
> - 인덱싱(Indexing)과 슬라이싱(Slicing)의 개념을 이해한다.
> - `loc`(이름·레이블 기준)와 `iloc`(위치 기준)의 차이를 알고 사용할 수 있다.
> - 행과 열을 동시에 선택하여 원하는 데이터만 추출할 수 있다.

데이터: 1~3차시와 같이 seaborn `penguins` 를 씁니다.

---

## 인덱스(Index)란? 🏷️

표에서 각 행을 구분하기 위한 고유 번호(이름표)입니다.  
학교에서는 학번, 사람을 구분할 때는 주민등록번호처럼, 한 줄마다 겹치지 않는 이름이 있어야 “이 학생”, “이 사람” 행을 정확히 집을 수 있습니다.

| 일상 예 | 역할 |
|---------|------|
| 학번 | 그 학생 한 명의 성적·출석 행을 가리킴 |
| 주민등록번호 | 그 사람 한 명에 해당하는 기록을 가리킴 |
| 펭귄 일련번호 `P001` | 그 펭귄 한 마리 관측 행을 가리킴 |

판다스 `DataFrame`도 마찬가지입니다. 왼쪽에 보이는 인덱스가 “이 행의 이름표”이고, `loc`은 그 이름표로 찾습니다.

이번 차시에서는 펭귄마다 `P001`, `P002`… 를 붙여 인덱스로 씁니다.  
표에서 맨 위가 몇 번째 줄인지(0, 1, 2…)는 줄 위치이고, `P001` 같은 일련번호와는 다릅니다. (`iloc` vs `loc`은 아래에서 다시 정리합니다.)

> 📌 펭귄 데이터에는 원래 이런 인덱스 열이 없습니다.  
> `species`, `island`, 부리 길이 같은 관측 내용만 있고, 학번처럼 한 마리마다 붙은 고유 번호는 없어요.  
> 그래서 아래 준비 코드에서 `P001`, `P002`… 를 우리가 임의로 만들어 `set_index`로 인덱스(이름표)로 지정합니다. 실무에서도 표에 고유 ID가 없으면 이렇게 새로 붙이는 경우가 많습니다.

## 실습 전 공통 준비 코드 (복사 실행용)

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.  
> (`P001`부터의 일련번호를 만드는 부분이 바로 위에서 말한 “인덱스를 새로 붙이기”입니다.)

> 코랩 실행 팁: `import`와 `df = ...` 는 한 블록에 넣었습니다. 표를 보려면 `head()`만 다음 셀에 두면 됩니다.

### 준비 — 라이브러리 + 데이터 + 펭귄 일련번호 인덱스

```python
import pandas as pd
import seaborn as sns

df = sns.load_dataset("penguins")
df = df.dropna().reset_index(drop=True)
df.insert(0, "펭귄번호", [f"P{i:03d}" for i in range(1, len(df) + 1)])
df = df.set_index("펭귄번호")
```

### 출력 — 인덱스가 P001부터인지 확인

```python
df.head()
```

> 💡 왼쪽 인덱스 열이 `P001`, `P002`…이면 준비가 끝난 것입니다. `iloc[0]` 은 “맨 위 줄”, `loc["P001"]` 은 “이름표가 P001인 줄”입니다.

---

## 1. 데이터에서 원하는 부분만 꺼내기 🎯

데이터프레임이 수백 행짜리 큰 표라고 생각해 봐요. 그중에서 내가 원하는 정보만 콕 집어 가져오고 싶을 때가 있죠.

### 두 가지 핵심 용어

| 용어 | 의미 | 예시 |
|------|------|------|
| 인덱싱(Indexing) | 특정 한 개(또는 몇 개)를 꺼내기 | 일련번호 `P001` 행만 |
| 슬라이싱(Slicing) | 연속된 범위를 꺼내기 | `P001`부터 `P003`까지 |

### ⚠️ 헷갈리기 쉬운 점 (꼭 읽기)

| 구분 | 무엇을 가리키나 | 숫자 예 |
|------|----------------|---------|
| `iloc`의 0, 1, 2… | 표에서 몇 번째 줄인지 (항상 0부터) | `iloc[0]` = 맨 위 줄 |
| `loc`의 P001, P002… | 우리가 붙인 일련번호(이름표) | `loc["P001"]` = 이름표가 P001인 줄 |

맨 위 줄은 `iloc[0]` 이고 `loc["P001"]` 입니다. 숫자 0과 문자 P001은 같지 않습니다.  
슬라이스도 다릅니다: `loc["P001":"P003"]` 은 끝(P003)을 포함하고, `iloc[0:2]` 는 끝(2번 위치)을 빼고 0·1번 줄만 가져옵니다.

---

## 2. 두 가지 마법의 함수: `loc`와 `iloc` ✨

| 함수 | 기준 | 외우는 법 |
|------|------|-----------|
| `loc` | 레이블(P001, P002…) | L = Label |
| `iloc` | 정수 위치(0, 1, 2…) | i = integer Location |

> 💡 둘의 느낌
> - `loc`: 이름표가 P001인 행 (슬라이스 끝 포함 가능)
> - `iloc`: 표에서 맨 위에서 0번째 행 (슬라이스 끝 제외)

---

## 3. `loc`: 일련번호(레이블)로 찾기 🏷️

### 한 행 전체

```python
df.loc["P001"]
```

### 여러 행 (리스트)

```python
df.loc[["P001", "P003", "P006"]]
```

### 슬라이스 (끝 포함)

```python
df.loc["P001":"P003"]   # P001, P002, P003 행
```

### 특정 행 + 특정 열

```python
df.loc["P001", "bill_length_mm"]
df.loc["P001", ["species", "bill_length_mm", "body_mass_g"]]
df.loc["P001":"P003", ["species", "flipper_length_mm"]]
```

---

## 4. `iloc`: 순서(0,1,2…)로 찾기 🔢

```python
df.iloc[0]
df.iloc[-1]
df.iloc[0:2]
df.iloc[0:2, 3:6]
```

> ⚠️ `iloc[0:2]` 는 맨 위·그다음 줄 두 줄입니다(끝 2는 포함 안 됨). `loc["P001":"P003"]` 과 행 개수가 다를 수 있습니다.

---

## 5. `loc` vs `iloc` — 같은 “앞쪽”을 가져와도 다름

### 출력 — 나란히 실행해 보고 행 개수를 비교하세요

```python
df.loc["P001":"P003"]
```

```python
df.iloc[0:2]
```

| 코드 | 가져오는 행 (예시) | 대략 몇 행? |
|------|-------------------|------------|
| `loc["P001":"P003"]` | P001, P002, P003 | 3행 (끝 포함) |
| `iloc[0:2]` | 맨 위, 그다음 | 2행 (끝 제외) |

---

## 6. 종합 예시 (펭귄 데이터)

```python
df.loc["P001", ["species", "bill_length_mm"]]
df.iloc[0:3][["species", "island"]]
```

---

## 7. 자주 하는 실수 ⚠️

- `loc`에는 일련번호 문자열을 씁니다: `loc["P001"]` (따옴표). `loc[0]`처럼 0만 쓰면 없는 이름표라 오류가 날 수 있습니다.
- `iloc`에는 0부터 하는 줄 번호만 씁니다. `iloc["P001"]`은 안 됩니다.
- 맨 위 줄 = `iloc[0]` = `loc["P001"]` (준비 코드 기준). 숫자 0과 P001을 같은 뜻으로 쓰지 마세요.

---

## 8. 정리하기 ✏️

- `loc[행, 열]`: P001 같은 이름표 기준, 슬라이스 끝 포함 가능
- `iloc[행, 열]`: 0, 1, 2… 줄 위치 기준, 슬라이스 끝 미포함
- 이번 차시는 일련번호 인덱스 덕분에 “이름표(`loc`)”와 “줄 번호(`iloc`)”를 구분해 연습합니다.
