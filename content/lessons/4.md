# 4차시: 원하는 데이터만 쏙쏙! 인덱싱과 슬라이싱

> 🎯 **이번 시간 학습 목표**
> - **인덱싱(Indexing)**과 **슬라이싱(Slicing)**의 개념을 이해한다.
> - `loc`(이름·레이블 기준)와 `iloc`(위치 기준)의 차이를 알고 사용할 수 있다.
> - 행과 열을 동시에 선택하여 원하는 데이터만 추출할 수 있다.

**데이터**: 1~3차시와 같이 **seaborn `penguins`** 를 씁니다. `loc` 연습을 위해 행을 **0, 1, 2… 번호**로 인덱스로 두는 준비 코드를 먼저 실행하세요.

## 실습 전 공통 준비 코드 (복사 실행용)

> 이 차시 실습을 위해 처음 코드창에 작성하는 초기 설정 코드입니다.

> **코랩 실행 팁:** 한 셀을 실행(▶)하면 그 셀 안의 코드는 **위에서 아래로 모두** 실행됩니다. **`+ 코드`로 셀을 추가**한 뒤, **번호 순서대로** 블록마다 복사해 실행하세요. (앞 단계를 실행한 뒤에야 다음 단계의 `df`가 맞습니다.)

**1단계** — 라이브러리

```python
import pandas as pd
import seaborn as sns
```

**2단계** — 데이터 불러오기

```python
df = sns.load_dataset("penguins")
```

**3단계** — 결측 행 제거 후 행 번호 0,1,2…로 다시 매기기

```python
df = df.dropna().reset_index(drop=True)
```

**4단계** — 맨 앞에 `번호` 열 넣기

```python
df.insert(0, "번호", range(len(df)))
```

**5단계** — `번호`를 인덱스로 쓰기

```python
df = df.set_index("번호")
```

**6단계** — 잘 바뀌었는지 앞부분 확인

```python
df.head()
```

## 1. 데이터에서 원하는 부분만 꺼내기 🎯

데이터프레임이 수백 행짜리 큰 표라고 생각해 봐요. 그중에서 내가 원하는 정보만 콕 집어 가져오고 싶을 때가 있죠.

### 두 가지 핵심 용어

| 용어 | 의미 | 예시 |
|------|------|------|
| **인덱싱(Indexing)** | 특정 한 개(또는 몇 개)를 꺼내기 | "번호 0번 행만" |
| **슬라이싱(Slicing)** | 연속된 범위를 꺼내기 | "0번부터 2번까지" |

---

## 2. 두 가지 마법의 함수: `loc`와 `iloc` ✨

| 함수 | 기준 | 외우는 법 |
|------|------|-----------|
| **`loc`** | **레이블**(지금은 번호 0,1,2…) | **L**abel |
| **`iloc`** | **정수 위치**(0부터 순서) | **i**nteger Location |

> 💡 **둘의 느낌**
> - `loc`: "인덱스 **레이블이 0**인 행" (슬라이스 끝 **포함** 가능)
> - `iloc`: "표에서 **맨 위에서 0번째** 행" (슬라이스 끝 **제외**)

---

## 3. `loc`: 레이블(번호)로 찾기 🏷️

### 한 행 전체

```python
df.loc[0]
```

### 여러 행 (리스트)

```python
df.loc[[0, 2, 5]]
```

### 슬라이스 (끝 **포함**)

```python
df.loc[0:2]   # 번호 0, 1, 2 행
```

### 특정 행 + 특정 열

**1단계** — 번호 0행, 부리 길이 한 칸

```python
df.loc[0, "bill_length_mm"]
```

**2단계** — 번호 0행, 여러 열

```python
df.loc[0, ["species", "bill_length_mm", "body_mass_g"]]
```

**3단계** — 번호 0~2행, 일부 열만

```python
df.loc[0:2, ["species", "flipper_length_mm"]]
```

---

## 4. `iloc`: 순서(0,1,2…)로 찾기 🔢

**1단계** — 첫 행

```python
df.iloc[0]
```

**2단계** — 마지막 행

```python
df.iloc[-1]
```

**3단계** — 0, 1행만 (끝 인덱스 2는 **미포함**)

```python
df.iloc[0:2]
```

**4단계** — 행 0~1, 열 위치 3~5 (끝 열 위치 6은 **미포함**)

```python
df.iloc[0:2, 3:6]
```

> ⚠️ **`iloc[0:2]`는 2행이 아니라 0,1 두 행!** 끝 인덱스 2는 빠집니다.

---

## 5. `loc` vs `iloc` 슬라이스 끝 처리

**1단계** — `loc`: 번호 0, 1, 2 → **3행** (끝 포함)

```python
df.loc[0:2]
```

**2단계** — `iloc`: 위치 0, 1 → **2행** (끝 제외)

```python
df.iloc[0:2]
```

---

## 6. 종합 예시 (펭귄 데이터)

**1단계** — 번호 0번의 종과 부리 길이

```python
df.loc[0, ["species", "bill_length_mm"]]
```

**2단계** — 처음 3행의 종·섬

```python
df.iloc[0:3][["species", "island"]]
```

---

## 7. 자주 하는 실수 ⚠️

- 인덱스가 **이름 문자열**일 때와 **숫자 번호**일 때 `loc`에 쓰는 값이 달라집니다. 이번 차시는 **번호 = 0,1,2…** 로 맞춰 두었습니다.
- `iloc`에 열 이름 문자열을 넣지 않습니다. 열 위치는 숫자로만.

---

## 8. 정리하기 ✏️

- **`loc[행, 열]`**: 레이블 기준, 슬라이스 끝 **포함** 가능
- **`iloc[행, 열]`**: 0부터 순서, 슬라이스 끝 **미포함**
