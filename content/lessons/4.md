# 4차시: 원하는 데이터만 쏙쏙! 인덱싱과 슬라이싱

> 🎯 **이번 시간 학습 목표**
> - **인덱싱(Indexing)**과 **슬라이싱(Slicing)**의 개념을 이해한다.
> - `loc`(이름 기준)와 `iloc`(위치 기준)의 차이를 알고 사용할 수 있다.
> - 행과 열을 동시에 선택하여 원하는 데이터만 추출할 수 있다.

---

## 1. 데이터에서 원하는 부분만 꺼내기 🎯

데이터프레임이 100명, 1000명짜리 큰 표라고 생각해 봐요. 그중에서 내가 원하는 정보만 콕 집어 가져오고 싶을 때가 있죠.

### 일상 속 인덱싱 비유

- 📚 책에서 **3장만** 읽고 싶다 → 책 인덱싱
- 🎵 플레이리스트에서 **1번부터 5번 곡까지** 듣고 싶다 → 슬라이싱
- 📱 친구 목록에서 **'민지'만** 찾고 싶다 → 이름 기반 인덱싱

### 두 가지 핵심 용어

| 용어 | 의미 | 예시 |
|------|------|------|
| **인덱싱(Indexing)** | 특정 한 개를 꺼내기 | "5번 학생만 보여줘" |
| **슬라이싱(Slicing)** | 연속된 범위를 꺼내기 | "3번부터 7번까지 보여줘" |

---

## 2. 두 가지 마법의 함수: `loc`와 `iloc` ✨

판다스에서 데이터를 추출하는 가장 강력한 도구가 바로 이 둘이에요.

| 함수 | 기준 | 외우는 법 |
|------|------|-----------|
| **`loc`** | 이름(레이블)으로 찾기 | **L**abel = 이름표 |
| **`iloc`** | 숫자 위치(순서)로 찾기 | **i**nteger Location = 정수 위치 |

> 💡 **둘의 핵심 차이**
> - `loc`: "민지라는 이름의 학생 데이터 줘!" (이름으로)
> - `iloc`: "0번째에 있는 학생 데이터 줘!" (순서로)

---

## 3. 실습 데이터 준비하기 🎒

이번 차시는 학생 이름을 인덱스로 사용하는 데이터를 써볼게요.

```python
import pandas as pd

# 데이터 불러오기
df = pd.read_csv('students.csv')

# '이름' 열을 인덱스로 설정 (이름표로 만들기)
df = df.set_index('이름')
df
```

### 결과: 인덱스가 이름이 된 표

| 이름 | 반 | 성별 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|------|------|------|-----|--------|------|------|------|
| **민지** | 1 | 여 | 162 | 50 | 85 | 90 | 78 |
| **서연** | 1 | 여 | 168 | 55 | 92 | 88 | 95 |
| **지우** | 2 | 여 | 159 | 48 | 78 | 82 | 70 |
| **하은** | 2 | 여 | 165 | 53 | 88 | 85 | 82 |
| **채원** | 3 | 여 | 170 | 58 | 75 | 92 | 88 |

> 🌟 이제 0, 1, 2, 3, 4 대신 **이름**이 인덱스 역할을 해요!

## 4. `loc`: 이름으로 찾기 🏷️

### 실습 1: 한 명의 데이터 가져오기

```python
# '민지'의 모든 정보
df.loc['민지']
```

#### 결과
```
반        1
성별       여
키        162
몸무게     50
국어       85
영어       90
수학       78
Name: 민지, dtype: object
```

### 실습 2: 여러 명의 데이터 가져오기

```python
# 민지와 채원의 정보 (리스트로 묶기!)
df.loc[['민지', '채원']]
```

> 📝 **포인트**
> 여러 개를 한꺼번에 가져올 때는 **대괄호 두 번** `[[...]]`을 써요!

### 실습 3: 슬라이싱으로 범위 가져오기

```python
# '민지'부터 '하은'까지 모두 가져오기
df.loc['민지':'하은']
```

#### 결과
| 이름 | 반 | 성별 | 키 | 몸무게 | 국어 | 영어 | 수학 |
|------|------|------|-----|--------|------|------|------|
| 민지 | 1 | 여 | 162 | 50 | 85 | 90 | 78 |
| 서연 | 1 | 여 | 168 | 55 | 92 | 88 | 95 |
| 지우 | 2 | 여 | 159 | 48 | 78 | 82 | 70 |
| 하은 | 2 | 여 | 165 | 53 | 88 | 85 | 82 |

> ⚠️ **`loc` 슬라이싱의 특징**
> 끝 값(`'하은'`)도 **포함**해서 가져와요! 4명이 모두 나왔죠?

### 실습 4: 특정 행, 특정 열 동시에 선택

`loc[행, 열]` 형식으로 사용해요.

```python
# 민지의 수학 점수만
df.loc['민지', '수학']      # 결과: 78

# 민지의 국어, 영어, 수학 점수만
df.loc['민지', ['국어', '영어', '수학']]

# 민지부터 지우까지의 수학 점수만
df.loc['민지':'지우', '수학']
```

> 💬 **외우기 팁**
> `df.loc[행, 열]` → "이 행과 이 열이 만나는 칸 줘!"

## 5. `iloc`: 위치(순서)로 찾기 🔢

`iloc`은 파이썬 리스트처럼 **0부터 시작하는 숫자**로 데이터를 찾아요.

### 위치 번호 이해하기

| 위치(iloc) | 인덱스(loc) | 데이터 |
|-----------|-------------|--------|
| 0 | 민지 | ... |
| 1 | 서연 | ... |
| 2 | 지우 | ... |
| 3 | 하은 | ... |
| 4 | 채원 | ... |

### 실습 5: 첫 번째 학생 가져오기

```python
# 0번째(첫 번째) 학생
df.iloc[0]      # 민지 데이터

# 마지막 학생 (-1은 끝에서부터 1번째)
df.iloc[-1]     # 채원 데이터
```

> 🌟 **꿀팁**
> `-1`은 **끝에서 첫 번째**를 의미해요. `-2`는 끝에서 두 번째!

### 실습 6: `iloc` 슬라이싱

```python
# 0번부터 1번까지 (2번 앞까지!)
df.iloc[0:2]
```

#### 결과
| 이름 | 반 | 성별 | 키 | ... |
|------|------|------|-----|-----|
| 민지 | 1 | 여 | 162 | ... |
| 서연 | 1 | 여 | 168 | ... |

> ⚠️ **`iloc` 슬라이싱의 함정!**
> `iloc[0:2]`는 0번과 1번만 나와요! **끝 번호(2)는 포함 안 됨!**

### 실습 7: `iloc`로 특정 행과 열 동시에

```python
# 0번째 학생의 0번째 열 (= 민지의 반)
df.iloc[0, 0]

# 0~1번째 학생의 2~4번째 열
df.iloc[0:2, 2:5]

# 0번과 2번째 학생의 모든 열
df.iloc[[0, 2], :]
```

> 💡 **`:` 의 의미**
> `:` 만 쓰면 **"전부"**라는 뜻이에요. `df.iloc[:, 0]`은 "모든 행의 0번째 열"이에요.

---

## 6. ⚠️ `loc`와 `iloc`의 가장 큰 차이 ⚠️

이 부분이 정말 중요해요! 잘 외워두세요.

### 슬라이싱에서 끝 값 포함 여부

```python
# loc: 끝 값 '포함' (끝까지!)
df.loc['민지':'하은']     # 민지, 서연, 지우, 하은 → 4명!

# iloc: 끝 값 '미포함' (앞까지!)
df.iloc[0:3]              # 0번, 1번, 2번 → 3명!
```

### 외우는 법 🎯

| 함수 | 끝 값 처리 | 비유 |
|------|----------|------|
| `loc` | ✅ 포함 | "민지부터 하은**까지**" → 둘 다 포함 |
| `iloc` | ❌ 미포함 | 파이썬 리스트와 동일! `[0:3]` → 0,1,2 |

> 💬 **선생님 팁**
> 처음엔 헷갈리지만 자꾸 써보면 익숙해져요. **"i가 들어간 iloc은 끝을 안 포함"** 이라고 외우세요!

# 데이터: 5명의 학생 (민지, 서연, 지우, 하은, 채원)

| 하고 싶은 일 | `loc` 사용 | `iloc` 사용 |

| 처음/끝 동시 | `df.loc[['민지','채원']]` | `df.iloc[[0, -1]]` |

## 8. 종합 실습: 다양한 추출 시나리오 🎬

### 시나리오 1: 우리 반 키 정보만 모아서 보고싶어요

```python
# 모든 학생의 키만
df['키']

# 또는
df.loc[:, '키']
```

### 시나리오 2: 처음 3명의 국·영·수 점수만

```python
# loc 사용
df.loc[:'지우', ['국어', '영어', '수학']]

# iloc 사용  
df.iloc[0:3, [5, 6, 7]]
```

### 시나리오 3: '서연'이의 수학 점수를 100점으로 수정

```python
df.loc['서연', '수학'] = 100
df
```

> 🎉 추출뿐 아니라 **수정**도 가능해요!

### 시나리오 4: 짝수 번째 학생만 골라보기

```python
# 0, 2, 4번째 학생 (민지, 지우, 채원)
df.iloc[::2]
```

> 🌟 **`::2`의 의미**
> `[시작:끝:간격]`에서 간격을 2로 하면 **2칸씩 건너뛰며** 가져와요!

## 9. 자주 하는 실수 ⚠️

### 실수 1: `loc`에 숫자 위치를 사용
```python
df.loc[0]            # ❌ '0'이라는 이름의 인덱스가 없으면 오류!
df.iloc[0]           # ⭕ 위치는 iloc!
```

### 실수 2: `iloc`에 이름 사용
```python
df.iloc['민지']       # ❌ iloc은 숫자만!
df.loc['민지']        # ⭕ 이름은 loc!
```

### 실수 3: 슬라이싱 끝 값 헷갈림
```python
# 5명의 학생이 있을 때
df.iloc[0:5]    # 0,1,2,3,4 → 5명 다 나옴 ⭕
df.iloc[0:4]    # 0,1,2,3 → 4명만! 채원이 안 나옴 ⚠️
```

### 실수 4: 대괄호 빠뜨림
```python
df.loc['민지', '서연']        # ❌ 행과 열로 해석됨!
df.loc[['민지', '서연']]      # ⭕ 두 학생 가져오기 (리스트로!)
```

## 10. 정리하기 ✏️

### 핵심 정리

- **`loc[행, 열]`**: 이름(레이블) 기준, 끝 값 **포함** ✅
- **`iloc[행, 열]`**: 위치(숫자) 기준, 끝 값 **미포함** ❌
- 여러 개를 가져올 때는 **리스트** `[ ]` 사용
- `:` 만 쓰면 **"전부"** 라는 뜻
