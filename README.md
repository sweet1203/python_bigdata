# GOO's 데이터 분석 with 파이썬

Google Colab 실습 중심 파이썬·pandas 데이터 분석 학습 웹앱입니다. 왼쪽 고정 목차·진행률·모바일 헤더 등 수업 포털 UI는 `data_literacy` 사이트와 같은 형식으로 맞춰 두었습니다.

## 공식 저장소

- https://github.com/sweet1203/python_bigdata

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 주요 경로

- `/` 홈
- `/learn` 학습하기
- `/quiz` 퀴즈
- `/progress` 내 학습 현황
- `/help` 도움말
- `/data` 데이터
- `/assessment` 제출 전 점검(루브릭·템플릿)
