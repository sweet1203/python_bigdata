# AC-DATA 코스웨어

빅데이터 수업용 코스웨어 웹앱입니다.

## 공식 저장소

- https://github.com/sweet1203/python_bigdata

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 주요 경로

- `/` 홈
- `/learn` 학습하기
- `/quiz` 퀴즈
- `/progress` 내 학습 현황
- `/help` 도움말
- `/data` 데이터
- `/assessment` 수행평가 준비실
