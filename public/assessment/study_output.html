4차시

인덱싱 · loc vs iloc

구분기준슬라이스 끝 처리
loc레이블(이름표) 기준끝 포함 — loc["P001":"P003"] → 3행
iloc정수 위치(순서) 기준끝 제외 — iloc[0:3] → 3행 (0,1,2)
⚠️ 수업에서는 인덱스를 P001, P002, P003… 형태로 설정했습니다. loc는 이 레이블을 그대로 씁니다.

loc (P001 형식)

df.loc["P001":"P003"] # 끝 포함 → 3행 df.loc["P001", "species"] # 행·열 하나 df.loc["P001":"P005", ["species", "body_mass_g"]] # 범위+열 목록 df.loc[["P001", "P004", "P008"], ["island", "flipper_length_mm"]] # 불연속 행
df.loc["P001":"P003"]  →  3행 반환 (P001, P002, P003 모두 포함)
df.loc["P001","species"]  →  'Adelie'
df.loc[["P001","P004","P008"], [...]]  →  불연속 3행 반환

iloc

df.iloc[0:3] # 끝 3 제외 → 0, 1, 2번 = 3행 df.iloc[0:2, 0:3] # 행 0~1, 열 0~2 df.iloc[-1] # 마지막 행 df.iloc[10, 2] # 11번째 행, 3번째 열의 값
df.iloc[0:3]  →
  species     island  bill_length_mm  ...
0  Adelie  Torgersen            39.1  ...
1  Adelie  Torgersen            39.5  ...
2  Adelie  Torgersen            40.3  ...

df.iloc[10, 2]  →  37.8
⚠️ loc["P001":"P005"] = 5행(끝 포함) / iloc[0:3] = 3행(끝 제외) — 끝 처리가 다릅니다.
